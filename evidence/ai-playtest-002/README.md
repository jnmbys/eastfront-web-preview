## 规则与选择理由

恢复仅在原恢复阶段提出原 `REPAIR_UNIT`：本方受损、未移动/攻击/使用炮兵支援、非专职铁路维修、补给正常、未恢复过、剩余名额及RP充足。公开铁路与当前可见占位估计基地范围；隐藏通路仍未知，Core可能拒绝。优先“损伤步数多 → 单步费用低 → 稳定ID”。例如定向场景中损伤2步步兵优先于损伤1步装甲；真实Core接受后只恢复1步并按原费用扣RP。双方单步恢复例均为损伤1→0、RP8→7，RNG不变。

筑垒仅在原筑垒阶段提出 `ENTRENCH`：本方未移动、非专职铁路维修、兵种允许、非首都核心、尚未筑垒；攻击过并不自动失去原规则的筑垒资格。真实Core将标志false→true，不扣RP。每次接受后按新视图重新评估，不为筑垒改变移动。

内部输入只补公开费用/次数/基地规则和本方当前阶段已接受的恢复回执。恢复配额可从本方回执重建；不依赖截断的16条短历史。任一维护动作被拒后，本阶段直接结束，不换单位反复探测隐藏条件。保留原拒绝总上限和搜索预算；维护候选最多127个加READY，铁路估计至多访问每个公开格/边一次。
