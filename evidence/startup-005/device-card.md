# STARTUP-005 下一次华为关键诊断操作卡

本轮不要求执行，不提供公网入口。下一次单独获准真机复验后，使用清单中源码 `380047b5dccd9cc247ac50d4fb3d81a2336df394` 的相同候选字节。

1. 默认模式打开一个新页面，地址附 `?startupDiag=1`。记下设备、网络及是否清过缓存；不要把新页面称为彻底冷缓存。
2. 启动一次并保持页面在前台。地图出现后收起面板，用游戏“＋”放大到上限；记录画面是否正常。诊断会分别保存请求景别、实际显示景别、缩放上限及视口。
3. 若近景完成，展开右下“启动诊断”，点 JSON 下载并保存一份截图。若地形细节仍未完成，进入地图约 90 秒后保存一次 JSON，再过约 30 秒保存第二份，用两份的 `stage/steps/lastAdvancedAt` 判断是否推进。未完成不视为通过。
4. 出现空白、缺图或报错，立即保存当时 JSON 和截图并停止，不刷新或重试。JSON 是否真实落盘以浏览器文件及内容核验为准；文本备份单列。

这次关键诊断只需一次默认启动。先分析上述证据，再决定是否需要单独串行对照；不要重复004整套步骤或凭一组观察宣称稳定提速。
