综合判断：保留了真实推进机会，目标距离改善，也有部分后续前进指标改善；然而更高的完全受困比例、德军损失与1017终局驻城减少，使“机动保护且整体安全获益”的采纳依据不足。**放弃当前方案的采纳，不继续本轮调参或扩样；代码只保留在实验分支供审阅，并非已接受或已部署版本。**
