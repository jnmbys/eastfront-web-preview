## 口径和重建方法

- `per-turn.csv` 包含全部4局的德军逐回合数据；候选阵营由文件名最后一段指定。候选德军是 `tune-17-GERMAN`、`tune-18-GERMAN`。
- 最近首都距离：每个整回合结束时，存活德军到公开首都 `(28,-5)/(28,-4)` 的最小六角直线距离。包括双方行动后的状态，沿用原 `record.turnDistances` 时点；不是MP成本或某固定单位的轨迹。`end.n` 指该回合最后记录行的零起始索引，文件行号为 `n+1`。`end.nearestUnits` 保存所有并列最近单位及位置，防止把样本单位变化误读成推进或后退。
- 移动格数：仅累计成功普通MOVE的 `path.length`（边数）；通过 `UnitMoved` 确认成功，拒绝不计，部署/战后推进/撤退不混计。移动单位数按本回合成功MOVE的unitId去重。攻击数为成功提交德军ATTACK，不把反应/结算重复计数。
- 损失分开记录：`lostSteps` 为德军 `UnitStepLost` 事件数，`destroyedIds` 为 `UnitDestroyed` 单位；末步损失不因另有Destroyed事件重复计步。损失按事件所在回合计，包含苏军行动或反应结算造成的德军损失，不限定提交行动的一方。
- 原日志没有保存逐步PlayerView、MP和结算事件。本次用固定版本RulesEngine**仅按原Action顺序重建**，包括3条拒绝；每次接受后完全按FairHost的 `derivePlayerView → rememberPlayerView` 更新双方知识。未调用agent、评分器或候选生成器；没有产生替代选择。German非部署阶段的1385个观察哈希与原 `observationKey` 全部一致；苏军观察未单独重建reinforcements DTO以校验哈希，但知识演进同FairHost。4局原trace哈希/字节/条数、接受/拒绝结果和最终状态哈希均一致，距离与原record逐回合一致，移动总格数与原record一致。共2748条现有Action；这是取证重建，不是新模拟对局或全量回归。
- 决策事实只取当时该方PlayerView：`visibleEnemies` 是IDENTIFIED；CONTACT只有位置，LAST_KNOWN未经确认，均不能补成已知兵种/兵力。权威事件仅用于赛后损失、移动消耗和拒绝分类，不回馈策略。
- `movement.maxMP/spentMP/unusedMP` 来自重建的UnitMoved；剩余数值不代表还能再次普通MOVE，因为成功MOVE已令hasMoved=true。未移动前锋的预算用当时movement减公开OOS惩罚1推导（本场景无全程道路奖励），与已执行动作的剩余值分开说明。
- 原日志未记录战略选中目标、路线势能、候选评分、放弃原因，JSON以null明确缺失。由固定源码和当时可见敌军只能确定目标**集合分支**，不能补造锁定的单个敌人、目标格或评分。MOVE路径终点也不能冒称战略目标。ATTACK.target则是实际记录的攻击目标。

逐局JSON：`rounds`（回合统计、最近单位、候选德军实际MOVE/MP和损失事件）、`nodes`（首次持平回合的行动前视图）、`goalModeSwitches`（从源码条件导出的目标集合分支）、`combat`（必要结算）、`rejects`（拒绝前视图和己方16条历史）。nodes只保留距离当前最小值不超过1格的己军及行动单位；其他己军没有被当作不存在。JSON压缩存储，原完整轨迹仍引用源回放。

四类解释分别处理：

1. **战斗/接敌约束**：上述前锋确实邻接可见敌军。`ai/fair/routing.ts` 的score明确在已识别敌军相邻时返回负无穷；prefix也在接敌处截断。这一源码分支条件在节点成立，足以解释为何该类前锋不提出普通MOVE；但没有证明Core无合法离开ZOC/绕路，也没有重算攻击候选或门槛，不能把攻击门槛指定为根因。
2. **路线偏离**：17全部261条实际MOVE边中216条缩短首都距离、45条持平；18为235/36；两局均无远离首都的边。按整次MOVE分别为107/17/0与117/6/0（更近/持平/更远）。说明存在侧向或等距运动，不能据此判定不合理绕路，更没有观察到向首都反方向往返。敌军邻格路线的策略目标与首都距离这个评估指标不同。
3. **目标切换**：两局T1 n60无已识别敌军，目标集合为公开首都；T2 n129开始有已识别敌军，此后德军决策均保留该条件。固定源码因而改用“可安全到达的已识别敌军邻格”集合。该模式切换可以确认；没有记录每单位唯一目标，无法证明它在多个敌军目标间反复切换。
4. **部队损失**：两局德军均无Destroyed事件，首次持平回合也无StepLost；原最近单位仍在原位置，故这两处持平不是最近单位消失造成的统计假象。T2损失可能改变后续战斗能力，但未做评分或反事实推断。仍须一般性保留“最近距离并非同一单位轨迹”的警告。
