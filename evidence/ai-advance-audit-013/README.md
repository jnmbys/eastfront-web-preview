**直接证据：对手决策因可见敌军出现而改变。** T2 苏军第一次移动决策 n161，B 的授权敌军列表为空，AI005 的目标是公开 objectives；C 仅识别 G-MOT-03@(11,1)，目标切为可见敌军旁的安全格。冻结 DTO 复现了两边实际选择。C 的 S-I-07 从 (13,0) 到 (12,1)，S-I-12 从 (11,-1) 到 (11,0)，S-TK-03 从 (11,3) 到 (11,2)；S-ART-01 原地不动。B 的 S-ART-01 到 (13,1)，S-TK-03 到 (12,2)，S-I-12 到 (12,-1)。关键苏军靠拢发生在下一次掷骰之前（RNG draws 仍为 2）。源码分支见 `frozen/ai005/routing.ts:62,92`，授权输入与原选择见 nodes 下对应检查。

**直接证据：首次持续落后是 T3 德军移动阶段末。** B 的 G-MOT-03 / G-PZ-04 均从 (10,1) 经 (11,1) 到 (12,1)，各花 2 MP，最近距离 16。C 的 G-MOT-03 留在 (11,1)，距离 17。C n199 与阶段末 n219 的冻结检查均为：`hasMoved=false`、基础 MP=4、六个单步意图都在候选集中，但评分全为负无穷；离线 Core 检查六方向也全不合法。三个格 (12,1)/(11,0)/(11,2) 是敌占，另三个 (12,0)/(10,1)/(10,2) 为 ENEMY_ZOC_TO_ZOC。因此此节点没有漏选的合法前进 MOVE，也不是 MP 已耗尽、资格未重置或候选截断导致。基础 MP 不是可多次使用的“剩余行动池”。

## 归因判断与唯一最小修复建议（未实施）

【推断，有直接链条支持】推进评价只奖励当下距离并检查当前可见攻击/防御风险；它放行“进入已识别敌军相邻格”，但既有普通移动策略在这种邻接下完全停步。此例通过对手可见信息变化，引发其靠拢及实际 ZOC 封锁，随后攻击偏向侧方。这是明确的推进与后续机动能力衔接缺口；不是非法推进、隐藏情报泄漏或移动资格错误。换另一个同距推进单位会怎样，没有证据。

唯一建议：在 `chooseCombatAdvance` 加一个保守守卫——若当前单位不邻接已识别敌军，而推进目的地将与已识别敌军邻接，则沿用 PASS。只使用已有授权 DTO，并与现有移动邻接判据保持一致；不读取全知状态，不改 Core/对手/参数。本节点会被该守卫挡住，但其整体收益及是否改善终局 **未知、未验证**；可能放弃其他有益推进。本任务未写入该修复，也未增加样本。
