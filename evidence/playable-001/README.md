## 如何使用

1. 选德军或苏军，点“开始战役”。按原部署列表/地图选择位置并确认。普通入口不会启用flowFixture或commandScene；折叠的“定向流程检查”仅保留AI-002已有验证场景。
2. 未启用COMMAND也能直接选兵、开始移动、规划路径、确认移动、选择敌军并攻击。原阶段与待决控件在底部左侧；当前部队资料居中；辅助功能与计划在同一底部区右侧。平板开局默认展开操作区，可用“面板”收起以放大地图。
3. FLOW默认关闭。开启后仅当当前**人类授权视图所有本方存活单位均无步损**，且是本人恢复阶段、投影就绪、无待决/隐私门/错误时，600ms后提交原READY。存在任何己方损伤即保留人工选择，不扫描恢复合法性。不替AI决定，不跳补给、铁路、移动、战斗、筑垒或增援。
4. FLOW开启时恢复/筑垒共用连续整备说明与“完成恢复，继续筑垒”/“完成整备”按钮。仍然逐阶段确认，不提前收费、不排队跨阶段动作。取消开关、换会话/座位或版本变更会使旧自动票据失效；同一阶段最多尝试一次；收到拒绝即关闭，不反复试探。
5. COMMAND默认关闭。选中部队后点“加入计划”，再“标记目标”并点地图。可以不加成员只记目标。金色虚线仅表示计划，绿色实线仅表示本视角观察到的已执行己方路线；不保证路线可达。成员定位在待决中不会替代撤退/推进选择。
6. COMMAND关闭仅隐藏覆盖层/记录区并退出点选，实际行动不变；重新开启可查看本会话原计划。新对局清空；人工换边沿用AI-002先清空画面再建立另一方授权会话，旧计划/旧记录不进入新视角。此次采用更保守的会话隔离，接管重建会话后原座位计划也不恢复。

FLOW旧代码以本机RulesEngine和全状态身份作入口保护，不能直接用于AI-002的NetworkPlayerSession。适配位于 `src/playable/flow.ts` 和main绑定：只允许当前LocalAiClient的授权会话，仍调用既有readyForPhase；远端多人不启用。COMMAND原投影消费逻辑保留在 `src/playable/command.ts`，使用现有已过滤的presentation事件总线；不读取Worker权威状态。触摸/鼠标统一采用“选中后加入”按钮；未移植Shift快捷键，帮助文字已相应修改。
