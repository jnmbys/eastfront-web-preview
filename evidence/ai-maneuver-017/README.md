# AI-MANEUVER-017：邻敌单位有界机动实验

结论：机动能力增加，但本轮不支持替换014。两局新增邻敌移动接受117/86次，其中远离首都51/35次；全军平均终距13.19→13.62、12.50→14.31，最近距离均8→10。PZ04终距14→13、10→13；德损步6→4、3→5。两局自然T16苏胜、无首都控制。保留实验源码和证据，不追加变体、不部署。开发样本不代表整体增强，分叉后的战斗不是同骰对照。

## 冻结 n389 检查

读取015的实际冻结输入，归档散列与输入/状态散列保存在 `n389.json`。PZ04 从(14,1)可生成(14,0)→(14,-1)，首步分3.303030303，Core离线接受。该路线终距仍14；它不是015的(14,0)→(15,0)前进见证。规划器仍只为首步生成一个按原代价/坐标顺序选出的前缀，后者没有被强制加入。

原014选择READY；017按原排序优先PZ01，分3.3125，路径(12,-2)→(13,-2)。该首目的格无已识别邻敌，Core却因隐藏ZOC拒绝。原始拒绝不是输入策略的新信息：只给既有一般拒绝回执，不暴露问题码。n389整次离线排名搜索9次/展开414节点；未耗尽。PZ04候选出现与是否优先被选中必须分开。

初次定向测试错误断言所有新增候选都应被Core接受，因此1项失败（`tests-initial.log`）。查明PZ01是视图不可见ZOC后，仅修正这个新增测试的预期，保存Core拒绝与不可见性负例；未修改实验策略，没有为避开隐藏障碍调参。正式测试25/25通过（`tests.log`），包含既有MOVE006、pathfinding和ADVANCE014共20项，加5项017检查。

旧016证据中的“邻敌必为-Infinity/0搜索”断言是历史取舍审计，作为父提交证据原封保留，不作为017不变契约运行。既有途中停步、规则合法性、动态占位、预算退出、隐藏阻挡与014保护断言均未删除。批后又对两局全部实际德军MOVE按当时授权视图检查首步已知ZOC和途中停步，并逐步核对输入散列、Host结果与最终状态；见 `verification.json`。这是已有轨迹复核，不是新对局。

## 完整证据与复现

`full-records.json.gz` 无损保存两局trace/events/record/process日志和四份完整审计JSON；`archive-index.json` 列每文件路径、字节数、Git blob SHA与SHA256。`node evidence/ai-maneuver-017/archive.mjs --extract` 校验并恢复逻辑路径，存在文件时必须完全相同。之后可运行 `analyze.mjs` 或 `verify.mjs` 重读已存轨迹；不要重启有manifest的批次。

`run.mjs` 复用lab初始化、终局、事件指标、完整回放与原子日志；`observe.mjs` 仅处理授权DTO且不参与行动选择；`analyze.mjs`/`verify.mjs` 中的权威状态只用于离线评估。`manifest.json`、配置、源码、构建散列、完整日志及异常测试初稿一并保存。源码未在两局之后变更，全部提交带 `[CF-Pages-Skip]`，不部署、不扩大样本。

复现运行产物：依仓库锁文件备好依赖后执行 `node evidence/ai-maneuver-017/build.mjs`；它在缺少冻结目录时从不可变Git源码恢复014、AI005对手及011推进对照，逐项匹配历史散列。批后仅完善了这一构建恢复分支，策略、测试、配置、runner与被动诊断均保持批前版本；重新构建后运行身份完全相同。定向测试命令：`node --test ai/tests/maneuver017.test.mjs ai/tests/move006.test.mjs ai/tests/pathfinding.test.mjs ai/tests/advance014.test.mjs`。
