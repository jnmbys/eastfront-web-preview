## Delivered behavior and privacy
See REVIEW.md for audited DTO, source events, compatibility and eligibility. Both combat participants receive authorized true dice/result independently of decision ownership. Stable battle ID/revision links stage updates. Requirements and executed consequences are separate. Unit consequence details intentionally include OWN units only; enemy identities, routes, support sources and remaining strengths are omitted. No observer permission added. Optional capability negotiation is necessary because actual older decoders reject unknown model fields. Default v2/explicit v3 preserved. Archives are bounded to 32 battles and 64 consequence records per battle, with visible omission notices; server restart persistence remains outside scope.
