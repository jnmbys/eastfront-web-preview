## 具体修复

1. 原 `ai/local/build.mjs` 用execFileSync直接执行npm，在本机Windows实际返回ENOENT（windows-build-repro.log）。改为依次执行原package build的三个Node程序，保持构建步骤与隔离开关，新增根目录一键启动器。原审核脚本路径边界使用平台sep，避免Windows误报。
2. 原状态栏只写玩家视角，战斗反应时可能与顶部回合阵营不同；现在明确当前行动方，并把停止原因翻译成中文，同时保留诊断码。终局显示“对局已结束”。原退出、接管权限和30秒监视器未改变。首页明确主动能力缺口。
3. 公平测试中两条历史断言落后于既有代码：默认候选仍被假定全为单格，导入白名单没有014/022已有模块。修订为原单格菜单仍单格、完整菜单不超过16格、隐藏成对完整菜单相同；仅把已有advance/parameters/plan加入准确白名单。原隐藏ZOC合法性差异证明、Core禁入等断言保留。初次失败日志保留，未修改运行策略。
