# 华为：只做一次对照诊断

本轮尚未开放公网。收到后续已验证的本人 HTTPS 链接后再操作；不要使用旧临时网址。

1. 在华为平板浏览器打开链接，用本机设置的临时口令登录。填写型号、系统、浏览器，点一次 **“开始对照诊断”**。
2. **加载失败或卡住：** 点 **“导出诊断并结束”**，保存 `mp013-owner-diagnostics.json` 后停止，不刷新、不重试。下载失败时复制页面下方诊断文本保存。
3. **加载成功：** 保持前台，等页面提示五秒等待已完成；只点一次游戏内 **“确认移动”**。等恢复可操作后导出。若仍等待或报错，直接导出并停止，记录仍然保留缺失项。

本次不切候选版，不收十次样本。只需交回这一个 JSON；不要发送口令、cookie 或 token。窗口关闭前先保存导出，地图出现或棋子移动均不等于已经恢复操作。
