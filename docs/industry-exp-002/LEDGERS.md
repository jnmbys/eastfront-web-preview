# INDUSTRY-EXP-002｜三路线16回合账本

所有投入、产量、运力、损失和场景配置均为实验假设。公式见 [METHOD.md](METHOD.md)，结论见 [REPORT.md](REPORT.md)，逐单位库存和行动明细见 [LEDGER_DATA.json](LEDGER_DATA.json)。

满效/减效是**假定有目标、满足地图合法性时的单位攻击机会**，不是已经验证的Core攻击命令次数；联合攻击涉及多个单位时不能按此相加成多场战斗。修复单位本轮休整。T16沿用德军最终行动窗口，无E16结算。

- 装备：后方/前线/在途，单位E；回收残骸W不包含在可用装备里。
- 维护需求：当前行动时单位数对应需求→本次结算需求（含新编）。T16仍有名义需求，但不虚构终局结算。
- 运输：装备与SP实际共享负载/容量；压力＝尝试送到装备目标库存并把单位补到维护前4SP上限的总目标负载/容量，**不是维护短缺率**。
- 恢复：符合本实验休整、债务与伤阶条件的单位数/本轮实修阶数；仍需装备、P和每轮1单位名额。
- 伤阶：期末未恢复阶数；等待：本轮修复伤阶从入账到下一窗口可用的回合数。初始伤等待未知、不进入均值；“—”为未修复。
