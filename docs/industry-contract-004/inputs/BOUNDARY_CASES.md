# 九个边界实例｜候选账本期望，不是实战回放

所有数量是手工设计夹具。欠账数值使用full时钟dt=1、初始耗损累积0；不外推half时钟。q=¼SP；E2=½装备包E；P为人员包。示例步兵配方3P＋6E2，B=4q，整编需一个足额维护的边界，组织权重4，三阶。来源、通道值只用于本例，不写入真实配置。`cap`为该E上限，未用额度不结转。未列账户不变；无额外生产、投资扣款、战损或其他货流。没有真实地图坐标；“入口合法”是待未来执行器验证的前置条件，不是本轮已跑Core证明。

VP变化指所列资源事件的直接影响，均不自动发VP；涉及实际目标计分仍需批准清单。W数值仅在注明地点压力P_geo=0、长期压力S=0且本例为整个评分单位集合时成立，不宣称实际对局W。

- E3：O1仍在后方，付4q；旧步兵前线收4付4；40q额度用8、未用32；rearArrears=0。
