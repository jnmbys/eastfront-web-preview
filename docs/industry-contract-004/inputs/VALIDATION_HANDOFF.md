# 固定缺供验证合同、待决项及工业003最小重算清单

本文件规定后续应记录和判断什么。本轮不新增完整对局模拟，不实施候选接口，不重复INDUSTRY-INTEGRATION-003路线比较。

## 1. 固定缺供的对照条件

固定source/rules/scenario/profile SHA、随机种子与输入快照。必须有合法部署及路网状态证明，不能把移走敌军/手改控制权后的合成状态称合法检查点。

- **C0静态维护对照**：无敌方运输阻断，不新增进攻和收费机动；不新增工业/新编/候补负担。按现有规则处理必要阶段与固定增援，不能跳过强制增援或冻结军队名单来压需求。单位继续存在，真实维护/损耗不关闭。
- **C1同条件工业承诺账**：仅加入已批准的既定工业订单/候补与装备发运；与C0区分来源被后方消耗多少、货运用掉多少。不是重做三路线排名。
- **C2行动费用审计**：在另有授权的合法短分支中，记录真实攻击/机动额外支付；不把扣除攻击账后数学加回的SP当成真实反事实对局结果。

“无敌阻断”不等于无运输约束：自己的未修铁路、地形成本、固定枢纽、共享桥/W/T、来源上限都保留。若只有合成的无阻断网络，则标`SYNTHETIC_DIAGNOSTIC`，不能用于宣称存活/平衡通过。后续验证到哪个E就只报告到哪个E，不用总库存÷总缺口当精确死亡回合。

## 3. 如何归因，不能怎样归因

1. 先算逐单位净维护缺口`m_i=max(0,B_i−stockBeforeE_i)`。`Σ可用前线来源<Σm_i`证明存在**来源总量不足的必要缺口下界**，但不能定位哪支部队短缺，不能推出真实存活轮数。
2. 来源足够而实际维护不足不自动等于运输不足；还要查来源接入、控制/桥/ZOC、每边/W/T及维护分配见证。证据不全标`UNATTRIBUTED`。来源与运输可同时限制，允许`MIXED`，不强行选一个原因。
3. 工业装备占用后的剩余向量必须与无发运的同事实预算分开列；维护先保障时，装备仍可能挤占**攻击储备**而不是维护。库存目标缺口不能冒充维护缺口。
4. 记录实际动作支付，只能解释库存去向。声称“停止进攻就会存活”需要合法停止进攻对照，不能把历史扣费直接加回并保持之后战果/路径不变。
5. 总量33/38SP维护对各24SP来源是现有实验风险提示，不是每个回合实际需求（会受死亡/增援影响），也不是已经证明T几自动崩溃。

通过设计校准至少要观察：停止额外消费、无敌阻断时，合理可达部队有实际恢复机会；若全军仍持续因固定源缺口恶化，必须提交场景预算风险，不宣称玩家战略失败。此轮不预定“必须活到24”的假结果；记录首个欠额、D门槛、损耗、死亡、崩溃预警/结束的**实测E**，缺阶段即`NOT_OBSERVED`。

## 6. INDUSTRY-INTEGRATION-003需要重算的最小清单

不要求003重做路线比较，也不向其他Worker自动发送消息；本清单供Leader转交。003以其自身已批准起点/参数为准，不把本边界小数值复制成场景配置。

1. **既有E24的顺序差异**：003已有E1—E24，不新增一轮。仅在确认后的事件顺序改变时，从第一个受影响末轮事件更新E24；此前行动未变则保留T1—T23。若候补/入场影响更早决策，按该依赖点继续重算，不能只补最后一行。
2. **每笔工业新编的首次差异点**：OrderAccepted的P/E转escrow、每E候补B/source扣额、完成但等待入口、真实部署E/turn；仅重算相关来源与受影响路线下游账。未有合法入口数据时列两种边界输入（可入/受阻），不伪造真实入场。
3. **维护Owner去重**：对每个plannedUnitId×E验证最多一条REAR或FRONT；入场费0、前期后方费不退、前线stock0；旧定时增援不得套工业候补费重复收费。
4. **货运批次台账**：补齐dispatch/due/received/available和dest预留；现行L=1/3可沿用，但删除同E到货可追溯修复/下单或重复发运的隐含收益；维护保护证据不足标未知。
5. **末轮恢复与计分输入**：保留003已允许T24恢复的原结果；补核两方真实恢复窗口、P/E与RP唯一付款、德国恢复后的苏军行动及最终step。003先修后编、末轮不下单为政策而非禁令。R只取实际入场永久ID，原假定全入场的F结果仍为临时算例。
6. **结果标签**：分别报账本守恒、假设入口可用结果、实际合法事件（若有）、评分未知项；前线SP来源净额需要扣候补，不能保留旧满额来源同时另付后方费。

最小交接字段是本目录FIELDS；九个实例是局部验收向量，不是003路线结果。本轮不重算任何003敏感性；等待Leader确认完整合同SHA/decisionRef后，由工业Worker定向续算相关主路线、D及必要依赖，另存结果，不覆盖003原始账本、参数和审计。逐项答复及双方阶段映射见[CROSSCHECK](CROSSCHECK.md)。
