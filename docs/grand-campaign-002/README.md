## 试玩

仓库根 `npm run grand:geo`，打开 http://127.0.0.1:4191/ ，选择“地理战区002”。真实T1预设合法部署，双方各60单位；双方阶段及待决使用原有“明确接管”轮流人工操作。AI没有新增战略经营能力。刷新会结束当前局，不支持存档恢复。

- 中央：定位G-026，移动Y17→Z17，1移动点/0.25补给点，立即占领枢纽，收入到E末才增加。城市防守能改变原战斗表列；铁路占领不自动等于修通，德军仍须满足既有铁路修复条件。
- 北绕：G-025可由Y16→Y15→Z14，2移动点/0.5补给点，绕开中央城市正面，但走远后可能离开己方站场末端配送范围。必须保护通路或退回可供给位置；不是保证补仓的免费绕行。
- 南线：Y26河谷节点连向V29/AB29站场，湿地、河流和桥位使渡口与高岸支路有不同风险。支路供部队绕行，道路不会自动变成材料铁路。
- 工业闭环沿用001：T1在O29工区下单1P和2E2，E1完成；T2预约前送V29，E2到账；T3恢复G-059。铁路、工作预算和末端服务按原规则共用；前线净维护优先，材料不足余量会等待。

地理尺度为相邻格中心约10公里的设计尺度；采用26.6–32.1°E、52.5–55.35°N连续参考窗，约360×317公里。它是“东欧地理启发的原创战区”，不是1941历史复原或等距GIS配准。原渲染格网朝向保留：北↖、东↗。
