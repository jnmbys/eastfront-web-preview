## 契约状态与原结论的引用方式

RULE-CAMPAIGN-002负责统一契约。本任务只报告001实际怎样算，不决定下一T部署、候补费率、正式分配器、耗损时钟或双方阶段顺序。契约差异表已作为首个独立提交先行远端保存。

001的“下T自动入场”没有合法部署事件；pending也没有独立候补维护账。实际例子是B在T2下GI订单，E2仍只付15SP维护，T3新ID入名册后才付16SP；这与工业003本E便维护新编的临时口径不同。两者都不能作为已确认合同。

T24不恢复属于实验政策，不能成为正式禁令；合法恢复可能改变同轮防御与E24组织损失。本轮不重算末轮恢复，也不把实际阶段顺序替换进同时攻防的代理模型。原001审计的“通过”仅证明其临时假设内部算术一致。

对001建议也作范围收紧：**不延续“下一轮必须出现反攻成功”作为验收门槛。** 归因实验应允许假说失败，并完整保留失败证据；不能为得到成功反攻而改阈值、来源或模型。

## 满支付上界能证明到哪里

诊断U逐单位计算：固定保存名册、伤阶、D、恢复排除与取整方式，把攻击支付因子设到足额，再相加；敌防御保持该T保存值。它不发SP，不改变策略，不执行战斗，也不把结果传入下一轮。

- 苏军B T13的`U−1.05D=−51.4`：支付不足不是该快照零净压的充分解释。冻结兵力结构及聚合公式已经构成限制。
- C push T21的`U−1.05D=57.2`，实际仅26.2：支付折损足以解释两者差距，但不能由此声称“保证会攻下节点”。T22以后上界也为正，实际却为0，显示它与苏军窗口不同。
- B T7/T10上界高于门槛，但实际进攻间歇及推进衰减阻止第三次易手。把各T上界跨轮累计会创造未保存过的对局，本轮未这样做。

单链掩盖了绕袭这一机制空间，但“如果有绕袭会解决多少停滞”无法归因。没有多线状态、目标可达性、局部兵力分配或合法战斗记录，本任务不作反事实胜负判断，也不开发替代系统。
