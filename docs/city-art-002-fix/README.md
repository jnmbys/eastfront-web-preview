## 更新行为

旧实现使用全局 revision 作为整层失效条件。现在忽略无关 revision 的变化，按永久 districtId、facilityId、cityId 和交通 edge key 对各自的实际绘制输入进行比对。

- 静态城区与城市外墙：几何/类型/槽位/交通方向/LOD真正变化才更新对应对象；单纯时钟、单位或资源修订不重建静态DOM。保持根节点、未变化的子节点和正在进行的细化任务。
- 设施：每个永久设施或空槽位独立更新；一座厂房变化不替换另一座。相同的设施输入连临时SVG解析也跳过。
- 交通：每条边独立更新；桥梁已知完整、损坏、修复和未知仍使用原绘制方法，不进入静态底图。
- 授权：每次调用都核对输入，包括相同 revision。删除设施、删除城市/边、显式隐藏城区立即移除旧DOM；细化任务不能复活已删除城区。换 viewer 清除旧设施、标签与交通对象；公共静态几何可保留。退出也移除仍挂在宿主上的城市图层。

## 点击行为

直接点击无单位/行动目标遮挡的城区完整六角范围，就打开该城市和城区面板；触控命中范围从小标签扩到实际城区。没有新增覆盖单位的大透明点击层，也不向邻近野地扩大城市范围。辅助小标签保留键盘 Enter/空格入口。

事件在SVG冒泡阶段处理，单位和行动目标先接收。宿主的 `canInspect()` 在点击当时求值：移动、进攻、撤退、增援等目标选择及军官选目标时不打开城区；普通选择、恢复/筑垒和铁路模式下的空白城区可以检查，实际铁路/单位目标仍优先。拖动、缩放、多指及取消手势不转成城区检查；下一次干净点击恢复。
