# GRAND-CAMPAIGN-001 · 1280格可运行候选

基线 PLAYABLE-004 `b7f5644c619c461e2f2d2a3d642670b572913d65`。独立分支 `grand-campaign-001-1280`。本地可玩、未部署；实验参数不代表历史精确或战役平衡。没有修改 OFFICER 调度/接管实现。

## 启动与操作

在本分支仓库根运行 `npm run grand`，打开 http://127.0.0.1:4190/ ，主菜单选择“大战略实验战役”。需要现有 Node ≥22 和依赖。服务只监听本机；一个页面会话一份权威状态，最多4个本地会话，刷新/重启不提供存档恢复。

新建即为真实T1：120次合法初始部署与双方准备操作从新配置生成，无T5存档/检查点导入。双方各60单位、5个集团军标签；标签不加战斗能力。本轮采用预设部署，不提供重新编辑开局部署的位置界面。

1. 用既有选兵、开始移动、路径格、确认移动和攻击按钮作战；近景可精细选兵，远景简化标记。“本方部队定位”可选择并居中部队。
2. 侧栏选后方工厂，下单装备或拨补人员。每方每T最多2单；装备3I得2E2，人员2I从有限已训练池划出1P。
3. 每方依次结束本方阶段；轮到另一方或战斗待决时用顶部既有“接管”并确认。这里是本机双方人工操作，AI不会经营新经济。
4. 双方阶段和待决全部完成后统一E结算。T1下单→E1入库→T2能预约铁路前送→E2到账→T3可恢复。
5. 运输选择货源与前线仓；按钮预约1P＋2E2。先满足可行净维护、再材料、再补储备；阻断/无余量会等待，可取消预约。
6. 受损部队必须位于己方材料仓同格，在恢复阶段满足Core资格；恢复一步消耗1P＋2E2，RP不扣。恢复不是自动发生，不免部队维护。

最短可复现练习：T1在C29后方各下一笔P和E2，T2继续两单并将第一批发往P29，T3恢复初始损伤的G-059；T4让其移动/继续作战。初始伤兵只是场景明示条件，所有订单、到账和恢复均是新对局真实结算。中央G-026两格可占T17枢纽，收益到E1才增加，首回合已有可选接触战。

旧模式仍在同一菜单：原640格AI对局独立运行；原PLAYABLE-004工业模式需另启其原4186服务，4190仅代理，不替换其账本。
