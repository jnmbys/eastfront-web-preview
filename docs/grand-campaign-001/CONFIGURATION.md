# 集中实验口径（仅 GRAND 模式）

权威数值入口为 `experiments/grand-campaign-001/config.json`，场景几何生成在 `scenario.mjs`。以下均为本次新增实验假设，未引用旧A10/C10、G-I-01、T5/E8特批，不修改旧SUPPLY/工业候选。布局目前固定32×40、5条战线×每方12单位；改变布局维度须另审生成器，不会静默套用错误坐标。

## 空间、兵力、节奏

1280格使用原Core纸面格名↔轴坐标。约10公里/格、1周/完整回合，T1–8突破、T9–16消耗、T17–24决战是指导，不是强制行动限制。北部森林/丘陵，中部平原，南部大河及桥路；五条横向铁路和后方/前线纵线形成可选通道。既有地形素材语义用矢量绘制新图，不拉伸旧640位图。

每方60单位：各战线4前锋、4支援、4预备，既有步兵、装甲、摩步、炮兵、工兵及侦察/反坦克模板，原移动/战斗能力不增加。每方最后两支步兵初始损伤1步，列为显式初始条件。集团军仅组织标签。S-037/S-049放在南部V22/V28，避免河流造成初始化即不可解的末端隔断。所有真实落点、地形、控制、铁路见可重生成T1清单。

## 初始化及持续经济

| 项目 | 每方实验值与来源 |
|---|---|
| 工业预算 | 一次性12I；5后方工业点各4I/E，中央三个争夺节点各2I/E归E时控制者 |
| 人员 | 一次性48P已训练后备池，是实验前提，不声称模拟过训练；不周期增人口 |
| 装备/材料仓 | 初始0P/0E2；20个双方后方/前线仓各96件材料容量，P和E2各占一件；与SP分开 |
| 装备单 | 3I→2E2，1周期；不消耗人员 |
| 人员单 | 2I＋后备池1P→仓内1P，1周期；I和P都一次扣除 |
| 下单上限 | 每方每T共2单，在己方受控工业点操作；无订单也正常推进 |
| 人员照管 | 每仓每E按ceil(P/4)扣1I组费，包括刚入库/刚到账；不足则现存P隔离，不自动复活或退款 |
| 补给来源 | 每方5×40SP/E＝200SP/E；单位初始4SP、上限6SP；1SP＝4q |
| 基础维护 | 一般单位1SP/E、装甲2SP/E；每方55×1＋5×2＝65SP/E |

工业点就是本实验的地图外产能/补给来源边界，产出直接在该工业仓交接；3I装备费/2I人员费包含边界内初次入库，不另占地图内铁路。地图外距离、全国生产链未建模；不解释成免费跨地图搬运。订单永久ID与输出批次关联，源池人员在接单时转入订单，不同时留池和仓。

占地按通过/到达的合法Core行动更新本模式控制；地点唯一ID同时承担VP/收入/补给源，单个E只按该地点一次结账。中途反复易手不即时发钱。E时失守工业停止原方收入/来源，控制者取得其周期收入/源资格；旧仓批次仍属于原方且停止服务，**不会免费缴获库存或取得旧方工厂下单权限**。占领者若缺少己方受控仓/可通行路，仍可能用不到该补给源。这是第一片的明确限制。

## E结算和守恒

双方行动及战斗待决→节点控制收入→到期订单入库（失守/满仓则保留已付待入库订单，后续E再试）→双方各自净维护→已预约材料运输→部队储备补足→人员照管→VP→E24终局。全部在同一原子提交内；失败回滚Core、经济、RNG、版本和战斗档案。

Tn订单在En完成，Tn+1才可用；不能同E刚生产又发运。Tn从此前已可用批次预约，En抵达，Tn+1才可恢复。各批次源仓扣出/目的仓新增及铁路扣额一起提交，无持久中间在途态（该实验把运输压在一个E内）。预约仍唯一保留在源仓；失败仍在源仓且不占实际运力；取消释放预约。重复ID返回原回执，改变同ID载荷拒绝；没有磁盘持久幂等承诺。

| 网络额度 | 定义 |
|---|---|
| 每条真实相邻铁路边192q/E/方 | SP与材料共享；完好铁路、桥和控制/ZOC约束；德军需己方已修铁路 |
| 每方T 30000 q·边/E | 每单位载荷×真实铁路边数，加SP末端格数 |
| 每己方受控仓W 192/E | SP配送及材料末端入仓共享；1P载荷4、1E2载荷2，1P＋2E2入仓8W仅一次 |
| 末端3格 | SP从仓至单位走真实相邻受控格，大河无桥拒绝；不为材料允许任意异格免费取料 |

先用部队自有库存支付，缺少的净维护优先走共享网络。随后按预约顺序送材料，最后补部队库存。路径择近是确定性贪心，不保证全局最优；没有把历史流量当余量。未消耗的周期SP来源额度到E结束失效，不变成无限仓库。足付维护可最多清掉当次维护量的旧欠账，清账不等于补满仓。

移动每格0.25SP，攻击每攻击者1SP；付不出的行动消耗记欠账。连续3个E维护不足损失一步，足付重置连续计数。空仓应用既有Core缺供状态/减效，其他Core补给资格仍在；本实验没有另造欠账攻击乘数。玩家可停止额外攻势、退回可服务范围、修铁路、护桥/源、减少前送争用来应对动态短缺。无敌破坏静止对照5E均足付基础维护，不证明所有战局永不缺供。

## 恢复、胜负与接口

同格己方材料仓1P＋2E2，保留Core的阶段、控制、损伤、次数等共同资格；每方每T最多6单位。只在本场景复制的模板中禁用RP价，外层事务原子核查并扣材料，记录消耗批次；不先扣RP再退款。不免维护，不新增单位。

24完整回合双方都可完成恢复。Core新增可选 `HOST_FULL_TURN` 检查点，只供本场景跳过旧T16首都胜负、在E24前停止进入T25；host完成E24账本后按当前控制VP判胜：总部6、工业3、前线枢纽2、争夺节点4，平分和局。E24新货标T25可用而战役已结束，不追溯T24、不折VP。没有首都丢失立即投降或战争意志系统。

复用原Action、授权快照、查询、FOW、战斗待决、恢复资格；新增独立host经济和场景。只发送本方库存/订单/部队，未知敌军不加远景计数。公开地图目标功能与期末总VP是公开信息。单一地图DOM，切换至新场景释放旧地形缓存；不双图常驻。新模式缩放上限12，部队定位按可视目标尺寸放大，旧上限2.5不变；矢量层不使用常驻变换栅格缓存。

## 最大风险与尚缺能力

参数刻意给足基本维护，20I/E收入与2单/T上限可能使I较快积累；未做整体平衡。材料网络/铁路源的贪心分配、阵地推进后仓距、捕获仓授权限制会影响进攻节奏。仅支持既有单位材料恢复，有限人员拨补，无新编/科技/全国训练。暂无经济AI、网络多人、存档恢复、长期压力/真机触屏验证。运行默认旧模式与640地图不受新参数影响。
