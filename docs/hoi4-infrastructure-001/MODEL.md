## 明确项目适配
| 项目 | 本候选 |
|---|---|
| 省与原版state | 复用固定省份ID/地块；不把六角当省 |
| 初始等级 | 现有道路端点覆盖至少25%省内陆地则2，否则1；固定于新局，不是历史基础设施普查 |
| 上限 | 5；等级独立，不消耗工厂建筑槽 |
| 成本 | 每级2100×6000/10800=1166⅔项目工时；保留两者成本比例，不冒充原版IC |
| 时间 | 5分钟一步、每民厂30工时/日、单线15上限；2座民厂5600步=19日10时40分 |
| 施工收益 | 工厂、枢纽新建/升级、厂房维修：基础工时×(1+0.2×所在地省等级)；基础设施自身、铁路新建/升级/维修不加成。自身排除是项目适配，不能从上述文件声称原版同样排除 |
| 末端 | 新发运人员/装备的每个地面路段，干燥工作量除以(1+0.1×该路段省等级)。路/越野原差异保留，再由实时雨泥决定消耗时间；铁路段不加速 |
| 容量 | 不增加火车、卡车、枢纽、来源、铁路共享流量，也不增加接收额度/库存；没有新货物账 |
| 在途 | 发运时冻结每段等级和干燥剩余工作，存档保存；后续升级不改旧批次、不倒扣时间。天气仍逐步影响剩余工作；原断路退库保护保留 |
| 占领 | 全省所有成员格受控才可开工/继续；任何格失守停工，夺回接续；已建等级保留，受控设施使用其所在地等级，不因省会换旗取得其他资产 |
| 连续等级 | 按创建先后逐项施工，排序不能让同省后级抢先；取消前级释放后级但不增加等级；所有阵营未完成预留共同计入5级上限 |
| AI | 仅苏军全局AI（双人关闭），每游戏日一次，自己队列空闲时选择自己全控且有设施、低于3级的省；同一合法ECON_BUILD接口、同样成本，没有补贴 |

等级只在整省当前可识别或己方实际控制时披露；未授权敌省为未知。地理边界公开不等于其当前设施等级公开。省份形状缓存；仅更新显示层，不改静态地形。
