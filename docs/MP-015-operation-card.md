# MP-015 人工操作卡

本轮桌面及华为单次诊断均已收到并核对，入口已关闭。以下保留本轮实际操作步骤，不应再访问旧链接或重复验收。结果与关闭状态见 MP-015-run.md。

## 先做桌面

1. 在本机 PowerShell 窗口设置临时口令，保留供浏览器登录使用，不发送到聊天。收到入口后，在电脑浏览器正常登录。
2. 设备栏填写 **Windows／实际浏览器**。页面标题虽然写“华为对照版”，桌面预检使用的也是这个固定页面。点一次 **开始对照诊断**。
3. 保持前台，等页面明确提示五秒等待已完成，再点一次游戏内 **确认移动**。等恢复可操作后，点 **导出诊断并结束**，保存 JSON。若下载失败，可保存页面下方的文本备份，并说明使用了备份。
4. 告诉助手文件路径、是否正常下载，以及是否遇到错误。**桌面记录核对通过之前，先不要在华为上测试。**

任一步失败或卡住，能导出就立即导出并停止，告知失败；不刷新、不重复点击、不换浏览器重试。助手将保存证据并关闭本轮入口。

## 桌面通过后才做华为

在华为上打开同一入口并正常登录，设备栏填写实际型号、系统和浏览器，只启动一次对照：

- **加载失败：** 立即导出并停止。
- **加载成功：** 保持前台并等五秒提示，确认移动一次，恢复可操作后导出；如果一直等待或报错，直接导出并停止。

桌面与华为的文件分别保存，不覆盖前一份。无需十次采样；不要发送口令、cookie 或 token。地图出现、棋子移动均不等于已经恢复操作。
