# 华为操作卡：一次暖机、三次移动

**本轮已完成并关闭，不再要求用户操作。** 以下保留本次实际操作卡；记录与限制见 [现场结果](MP-021-FIELD-RESULTS.md)，不能用旧链接重新开始采样。

1. 在华为同一浏览器、同一网络打开入口并正常登录。口令只在本机设置，不发聊天。填写型号、系统及浏览器版本，点一次“开始本局”。
2. **暖机**：目标准备好后保持前台，等“五秒已到”，点游戏内“确认移动”一次。等外层页面显示“已恢复操作”，点“导出本次”。
3. 确认 JSON 确实保存在设备上，再点“已保存，继续”。不刷新、不退出地图。选一个仍有 MP 的己方棋子 → 移动 → 相邻合法目标。
4. 按页面固定的 **正常1 → 正常2 → 正常3** 各做一次；每次仍等五秒、确认一次、等恢复、导出并确认保存。可以换另一个己方棋子，不结束回合。
5. 交回四份 JSON。启动失败、拒绝、断线、卡住或报错时，立即导出并停止，不刷新补测。JSON 无法保存时，滚动**外层页面到游戏框下方**复制文本备份；两条通道都不能保存就停止。

不需要十次或重复冷启动。暖机单列，三次正常记录只用于定位，不代表性能改善。结束后由执行方保存服务端记录并关闭临时入口。
