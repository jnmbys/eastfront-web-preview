## 固定模型（执行前）

- 地图固定轴坐标每8×8格划天气大区，约80公里尺度；分区不随归属、视野或镜头变动。双方共享公开天气，但军队与物流仍走原授权视图。
- 独立32位xorshift天气种子由开局种子异或固定盐初始化，不调用战斗random；当前随机状态与湿度入存档，不下发未来随机状态。
- 每6游戏小时统一更新晴/雨：原晴区降雨概率18%，原雨区持续概率70%，加相邻四大区上一时段雨区比例×18%。同步使用旧邻区状态，避免遍历顺序偏差。不是天气预报或真实气候数据。
- 每5游戏分钟积湿0.06/12；晴时排水0.015/12；湿度限制0–1。30%以下无泥泞惩罚，以上泥泞=(湿度−.3)/.7。满湿晴后约46小时40分退至非泥泞，66小时40分全干。
- 实际行军含撤退按干地工作量推进。道路耗时系数 `1+雨×.05+泥泞×.30`；越野 `1+雨×.15+泥泞×1.2`。与既有燃油限制相乘；无油不能因天气改善而移动。实际兵位仍到达才改变。当前路段ETA按当前条件估计，会改变；原寻路仍按已知地形道路成本选路，并未实现气象最优绕行。
- 既有补员/补装运输分期预留、吨位收费不变。已扣库批次分为装卸/铁路及沿实际末端路径的逐段工作：装卸与铁路不受泥影响，道路/越野使用同一上述系数。存进度，不因下雨重发、退货或重复收费。货物只有全部路段完成才到队。
- 本轮天气改变的是地面行程时间，不再次削减铁路、火车或枢纽吨位。日常供给流量、既有即时燃料配送、生产资源能力与战斗伤害不额外加天气系数；这是首版范围限制，不冒称完整BICE后勤天气。
- 新战役格式 `BLACKICE-WEATHER-001-1`；旧省份局和天气局双向拒绝跨载，仍保留旧省份子账版本。没有自动转换或初始资源调整。

以上所有概率、分区大小、积湿/排水率和移动系数均为**项目适配**，不是BICE逐值复刻。初始正常局全区晴且干燥，随后由固定种子自然变化；测试固定晴/雨/雨后状态必须单列夹具。
