## 为什么选细刻度

旧锚点5/5附近，1点是20%的跳动。新锚点10/10附近，1点是10%，能表达7/8、10/9及受损后的非对称衰减。粗刻度把推荐的受损装甲11对8压成6对4，会从1:1跨到3:2列。细刻度保留这类有用区别，但不消除CRT自身断点，也不代表史料精确到10%。

仅所有攻防乘2，在不取整时1100组跨阵营单位/损伤配对的CRT基础列不变；失补向上取整会打破这种等价。推荐包另行调整相对强弱、部分移动及耐久，**绝不是一次无效果的显示单位换算**。
