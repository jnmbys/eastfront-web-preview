# 单位语义与刻度选择

## 先定语义，不先定分数

基线没有年代、具体番号、兵力、公里/格、天/回合字段。它是32×20格、默认16回合的抽象战役；这些数字不能反推年代。本文选择**1941年11—12月组织形态**作为R1的设计条件，仍不声称重建某个实际战区。

一个棋子表示可以独立下令的一支**部队实体**，不保证同级、同人数、同正面宽度。所有A/D使用同一个比较单位：以一个状态较完整、包含本级通常支援的德军步兵师的普通地形作战能力为10/10锚点。A是进攻贡献，D是守住该战斗地域的贡献；都不是人数、坦克数、单车穿甲或士兵素质。不能用“每千人战力”填表后直接相加。

主力师三步，小型旅/团群两步，HQ一步。这是战斗组织持续能力的粗分，不是一次步损恒等于多少人死亡。较大装甲师与较小坦克旅不仅分数不同，耐久也不同；仍占一个格位、部分仍有同样ZOC，则作为公开的引擎简化保留，不能声称已完全统一部队正面尺度。

范围包含所属勤务人员，不等于前沿步枪手数量。以上没有真实单位逐一实力表，故不计算伪精确的全图历史人数或装备总数。后续若改成真实番号，须用具体日期/战区的实力表替换设计包络。

**不得双计装备**：师棋子已含其通常师属炮兵、工兵、侦察与反坦克贡献；独立支援棋子必须来自单列的上级配属资源。若将某师属侦察营抽出为G-RECON，则该营不能继续隐含在母师的装备账里。当前基线没有装备账，R1只定义去重原则，不声称已恢复真实总兵力。

## 苏军坦克与重坦：本轮作出的选择

H15将1941年坦克编制由较大的早期组织转为旅级支援力量，并列出旅纸面坦克数从早期93到年末46的变化。采用的是年末组织镜头，不把这些数相加、取平均或当实际实力。普通旅本来也可能有KV，因此R1重坦区别仅为同总规模下的装备配置偏重、攻防取向与速度；**不把“KV”乘成整旅更高人数、更厚血量、更大覆盖范围**。

S-TANK推荐8/6、两步，重坦7/8、两步。KV较强防护映射为较高D，但缺少步兵、侦察、炮兵和维修体系的弱点不会被单车装甲抵消。7与8均为D；两者不能据此推出坦克交换比。没有已核实的KV配额，故不捏造“固定N辆KV”的普遍编制。

不选“若干苏军坦克旅合成一个师等价棋子”：这会增加一个棋子的实际部队份额，现有58＋13槽位无法证明供给、兵力和地图正面仍相容。也不选“1941战前坦克师＋年末轻骑兵师”的无说明拼接。

## 骑兵只作两个一对一替换

`S-I-15`、`S-I-16`分别改为一支年末轻骑兵师，约3,000—3,400人的设计包络，骑乘机动、主要下马作战，步枪/机枪/迫击炮和有限轻炮；不赋予战前常规骑兵师的坦克团。H06给出轻骑兵小型化背景，H09/H11支持敌后活动和下马攻击的任务定位。

推荐4/5/4 → 2/3/4 → 消灭；不增加增援槽位。苏军初始步兵由16变14、轻骑兵2，苏軍仍32枚，德国仍26枚，增援仍13枚。替换表示减少正面步兵兵力以换取机动，**不承诺总人数不变**，也不把被替换步兵“剩余人数”再加到别处。其单位数与任何现实装备总量都没有上调。

轻骑兵ZOC与步兵协同保留，不能筑垒；无猎兵森林豁免、无林丘减费、无侦察ZOC穿越、无装甲突破。这些旗标是D。满编骑兵比徒步步兵更快、正面作战更弱；不将其泛化为所有年代骑兵都弱。道路/林丘按普通单位计费，马匹给养也不是免费。

## 四种量分别定标

|量|现状/选择|依据与限制|
|---|---|---|
|攻防A/D|德普通步兵10/10，表内非同比重分配|统一相对作战贡献，不是兵力计数；1点分辨率约锚点10%|
|移动MP|保持约2—6的现有区间；猎兵4→3，部分小单位损伤后下降|待公里/格与天/回合确认；道路、河流、ZOC、突破都是另一个合同|
|耐久步数|max3主力师、max2小部队、max1HQ|修改的是生存/恢复节奏；每步不等量，不从A/D自动推算|
|RP/SP|保持现有单位与价格，不乘2|RP是恢复预算，SP是补给预算；同费异规模是暂存简化，见SEAMS|

更细刻度保留整数显示与加法，不需要扩大CRT或乘地形修正。选择新锚点10只是最低足够用的分辨率，不采用50/100分制以免制造并无证据的精密性。粗刻度方案是将本候选A/D除2后四舍五入（`.5`向上），同样采用本包单位层级与损伤档，作为受控比较；它不是另一个完整推荐。
