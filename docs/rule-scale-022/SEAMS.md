# 实际契约与重复奖励审计

审计的是c4a31固定基线，不宣称覆盖正在独立推进的SUPPLY-UX-020或别的Worker新提交。源码路径相对仓库根；[validation.json](validation.json)记录SHA-256，脚本核对这些文件与基线内容一致。候选仅存在研究目录。

## “换刻度”与“改效果”必须分开

|改动|是否纯刻度|理由|
|---|---|---|
|全部单位所有档A/D同比×2，保持整数、不遇取整|是，限比例计算|总攻击/总防御同比，基础CRT列不变；修正仍按列|
|同比×2，随后每单位失补/低库存攻击向上取整|否|ceil(kA×f)不总等于k×ceil(A×f)，联攻会积累舍入差异|
|重定相对A/D、损伤曲线|否|比例可能跨CRT门槛，即使最终列有时被上限/下限遮住|
|移动4→3|否|道路、林丘、混合路径可达格数和进入敌ZOC的时机会变|
|3步→2步|否|同一CRT结果更易消灭，恢复/损耗/能力档的合同改变|
|数值提高后RP/SP不变|不是补给单位换算|其含义仍按一次恢复/单位维持计费；战斗效益/费用可能变化|
|骑兵一对一替换|否|层级、战力、机动、筑垒和类型归属变化；单位计数不变|

## 重复奖励与差异被吞掉的位置

1. **猎兵**：原5/5与普通师相同，再有4MP、林丘减费、全战森林豁免。R1降基础A/D与MP，只保留已有地形专长；丘陵没有攻击豁免。仍有“带一支濒损猎兵解除整个装甲集团森林惩罚”的接缝：R1受损JAGER贡献3点，占19点仅约16%，仍取消全战森林-1并可作为步兵协同。降低模板数值不能根除此问题。若未来采用有效战力份额/供给门槛，应单独设计，不能假装本包已经实施。
2. **装甲与摩托化**：G-PANZER师级内部合成能力已含在基础A/D，又有外部步兵参与+1列，存在部分重复解释。R1保留+1但不额外抬高满编装甲的相对锚点，也不把摩托化汽车算成额外攻击加成。PANZER＋INF对S-INF在平原仍封顶4:1+，细分分数在那里看不出来。
3. **重坦/反坦克**：S-HEAVY较高D仅表达同规模下的装备偏重，不再获AT标志、额外步数或独立减伤。S-AT的专长已是对攻击装甲-1列，维持较低普适D；步兵＋AT比单独AT合理。
4. **工兵/炮兵**：工程能力、炮兵±1列保留，故不用高普通A重复表达其支援贡献。两步改变暴露后的生存期，不新增火力机制。
5. **骑兵/侦察**：骑兵4MP不叠林丘折扣、免ZOC或装甲突破；侦察维持高MP和一次ZOC忽略，但普通战力和耐久低。速度是不同任务方式，非精锐等级。
6. **±2上限**：森林-1、缺步兵装甲-1、AT-1、筑垒-1合计-4，实际只-2；一项奖励可能只是从-4减为-3，最终列完全不变。表内不再把每项效果重复折算为固定A/D加成。
