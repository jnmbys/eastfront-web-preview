## 证据如何约束候选

- 猎兵：F两团轻步兵及非全摩托化 → I通用火力与道路速度没有当然优势 → D低于普通师的基础战力、相同3MP，优势留在已存在的林丘规则。8/8不是把两团/三团严格乘成2/3，也不是实战交换比。
- 苏军坦克：F年末小型化 → D明确单旅；不得既用旅的车辆构成，又领取完整装甲师的人数、耐久和防御覆盖。KV集中旅是I/D的装备偏重抽象，没有冒认一个固定史实编制。
- 苏军步兵/精锐：F大量组织与装备差异 → I应给出有限、状态相关差异 → D 7/8与9/10；不能用历史失败证明5:3，更不能把同一缺补重复扣罚。
- 骑兵：F小型轻骑兵与下马攻击任务 → I快于徒步的机动定位、重火力和持续正面能力较弱 → D 4/5/4、两步。没有据此否定早期常规骑兵或后期骑兵军的火力。
- 支援单位：公开层级为D的团/营任务群，承认没有对应具体编号。其存在是现有游戏抽象，来源不能证明这些棋子的人数设计包络或与一个师之间的固定倍率。
