# UI-008 Known Limitations

## Intended product limits

- Hot-seat local play only. No AI, network multiplayer, account system, cloud save, matchmaking, or telemetry.
- Browser refresh safely returns to the Home / New Game startup path; UI-008 does not implement persistence.
- Desktop and iPad landscape are the supported play baselines. Mobile portrait renders a graceful advisory rather than claiming full playability.
- No service worker or offline/PWA cache layer is included.

## Review-environment screenshot limitation

The container's headless Chromium process was able to start but the screenshot / DOM-export command did not complete within 35 seconds and produced no screenshot artifact. Stderr contained environment-level DBus / zygote errors. This is treated as an **optional screenshot-export blocker**, not as a production-runtime failure.

No fake screenshot was substituted.

Authoritative UI-008 evidence instead comes directly from the final compiled `dist/` modules:

- Home desktop / iPad: HTML generated by `dist/app/web/preview.js`;
- Turn 1 / combat: SVG generated by `dist/app/render/coreSvg.js`;
- privacy handoff / GAME OVER / mobile narrow: compiled production presentation helpers;
- production build audit: final `dist/` directory inspection.

Static-host verification separately requested `index.html`, CSS, JS, production map, manifest, P5R1 S02, and all 123 runtime rasters over HTTP; all returned 200 with zero missing-asset 404s.
