## 实现与授权

新规则 GRAND-TERRITORY-1 / 存档 GRAND-RELEASE-TERRITORY-1 / 握手 GRAND-RELEASE-TERRITORY-1。经济版本仍为GRAND-ECONOMY-2，生产、成本、补充、战斗步长与伤害均未改变。旧限时、第五日保持、兵力失能终局仅在旧规则保留，新规则不执行。无占领等待时间。

双方总进度为公开战略情报；计分格详情仅返回本方列表，实时控制取授权视图，缺失显示未知；不向敌方AI提供投降计分的隐藏逐格控制。终局由权威实际control统一计算。阈值配置随存档保存并校验配置散列，修改配置须明确新局，不静默重算旧分母。

苏军战略规划从授权视图选择关键计分城市，优先保护被发现威胁的重要本方地区，否则推进敌方公开计分点；旧中央目标达成后会继续选点。三军团只扫描固定20个重要点，通常每72步重评，已知目标易手可提前重评。组织不足先休整；保守战术轮换继续生效，玩家明确命令不被此逻辑覆盖。没有新增全图路径搜索或偷看敌方组织度，经济AI不变。
