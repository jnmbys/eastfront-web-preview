## 直接试玩

本机入口：http://127.0.0.1:4249/ 。交付时为 1941-07-01 06:00 暂停正常新局；德军对苏军 AI。此地址不是公网地址。

1. 点军官肖像选择军团，调整任务／目标，点「委托军团执行」。肖像选择不跳镜头，定位和暂停是独立按钮。
2. 点部队卡片；同格或跨格群组先展开成员，再点具体部队。直属用「直属」标识，受托单位显示所属军官。
3. 单位详情顶部直接提供移动、攻击、支援、撤回、停止。点动作，再点地图目的地，查看虚线路线与原因，点确认。取消不提交。无需展开两层命令菜单。
4. 向受托部队确认直属命令会接管该队。暂停世界仍可下令，继续时间才执行。停止／接管不保证已经脱离敌军攻击。交回军官使用下方选择框和按钮。
5. 战斗标记点击打开双方详情；绿色行军进度、红色主攻、蓝色支援保持原语义。支援结束不自动跟进。
6. 顶部保存；设置中可重连、读取存档。加载默认暂停；未确认的本地预览不保存，需重新选择，已接受命令照常保存。

关闭：先在网页暂停并保存，再运行 `powershell -File experiments/grand-ui-003/stop.ps1`。脚本只允许关闭 4249 上本任务入口进程，不删除存档。重新启动：在本分支目录运行 `node experiments/grand-ui-003/server.mjs`（需要先构建）。存档在 `%USERPROFILE%/.eastfront/grand-ui-003/4249`，原子保存与备份沿用发布候选。

回退：打开原 4247／4248 候选，保留各自独立进度；或在独立目录检出基线，按原启动说明运行。不要把新候选存档覆盖到旧正在运行的服务。

## 复现与实际修复

旧版接管后处于 HOLD/paused 是安全停止语义，不把它改成自动推进。真正操作障碍是单位详情外层和命令内层双重折叠，玩家看不到重新下令入口。新界面直接显示合法命令、目的地预览和拒绝原因；原 DIRECT/ASSIGN、代次、回执及接管规则保留。

另在平板检查中修复两处实证问题：触屏旧样式覆盖了 44px 下限；行军箭头穿过部队卡片时截获选兵。现在主要命令按钮统一至少 44 CSS px，箭头与卡片重叠位置优先选卡片，卡片外仍可查看箭头。切换面板／军团会取消未提交的点选，避免隐藏的下令模式残留。

路线预览通过现有 QUERY 通道，只消费本方公平视图和本队能力、现有有界寻路；不调用全状态合法性试算，不改状态或 RNG。预览绑定状态版本，版本变化须重新预览；实际命令仍由原权威事务裁决。

## 战斗标记口径

- 数字：去重后的本方已知参战单位组织度均值，四舍五入为 0–100；有缺失时显示 `?`。不读取敌方精确组织、人员或库存。**这是本方组织状态，不是钢四胜率，也不是伤害／行军完成率。**
- 方向：右箭为本方进攻，左箭为本方防守，双向箭为双方投入，弯箭为发生撤退。相对于观看方解释，不指地理东、西。
- 颜色：沿用既有授权接触报告，绿为暂能维持、赭为承压、灰为依据不足；另有文字／符号，不只靠红绿。暂能维持不等于即将获胜。
- 预计结束时间仍在详情，保持原估计对象与不确定性。新数值不反馈给战斗或 AI。

单位绿色条仍是组织，金色条仍是人员比例；装备缺额单列。原堆叠汇总、低组织警示、未知敌军限制未变。三张原创 SVG 肖像以固定 `officer:walter/roven/veil` 展示身份绑定既有三名军官；刷新和读档不重抽，不涉及性格或 RNG；直属没有虚构军官。
