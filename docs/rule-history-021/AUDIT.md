## 攻击、防御、移动、步数的实际意义

- **攻击A**：所有直接攻击单位有效攻击值求和，再除以守军防御总和，选择CRT列。是合成作战值，不是枪数、杀伤人数或单车穿深。
- **防御D**：目标格所有活守军的D求和。旧补给下，全部守军断供且无合法退路时总防御减半、向上取整。不是装甲厚度；重坦D7不等于一整个重坦师坚不可摧。
- **移动M**：该损伤档的MP预算，扣地形/河流成本；受ZOC与堆叠制约。M4不保证能走4格。
- **step 0/1/2**：三档损伤状态；普通单位第三次步损消灭。它既非移动步数，也非每步固定损失三分之一兵员。HQ的最大步损为1，虽列三档，通常后两档不可达。
- **恢复**：降低step一档、恢复相应A/D/M；装甲/摩托化/炮兵每步2RP，其余通常1RP。步损同时抽象人员、装备、组织损耗，不能再用纸面兵员比例直接套入。

代码定位：`rules/unit.ts:4`、`combat.ts:36–44`、`crt.ts:3–6`、`combatLoss.ts:24–26,143–151`、`recovery.ts:192`（均为`core/source/src/`下）。

CRT基础门槛为 `1:3 / 1:2 / 2:3 / 1:1 / 3:2 / 2:1 / 3:1 / 4:1+`，采用达到的最高门槛；最终修正净值封顶±2列，表为2D6。+1攻击并非固定收益：5攻打3防是3:2，6攻打3防跨到2:1；4攻与5攻打5防分别是2:3与1:1。

## 猎兵为何在体验中更强

本轮脚本只读运行vendor计算函数，做35个单格移动、30个战斗上下文探针，不运行对局。结果见 [audit.json](audit.json)。

|满编、满补给、无路无河无ZOC的均匀地形|普通步兵G-INF|猎兵G-JAGER|
|---|---:|---:|
|平原最大整格位移|3|4|
|森林/丘陵最大整格位移|1|4|
|ROUGH/沼泽最大整格位移|1|2|
|平原攻击S-INF（5攻对3防）|3:2列|3:2列|
|森林攻击S-INF|1:1列|3:2列|
|丘陵攻击S-INF|1:1列|1:1列|

森林4格对1格是离散MP成本与预算共同造成的结果，不是史实“猎兵快四倍”。其森林能力还能外溢到同场装甲；step2或断供猎兵依然满足取消森林惩罚的`some(JAGER)`条件，代码没有要求最低攻击占比或正常补给。以苏普通步兵作弱守军时，装甲合攻常已到CRT最高列，优势会被封顶掩盖，不能仅看该例就判断没有影响。另用D5的S-ELITE探针：森林中PANZER+INF最终2:1，PANZER+JAGER最终3:1，明确显示外溢。

数值候选先将猎兵M调回普通步兵档，并将A/D降低一档，以保留特定地形角色。若以后还要修改森林豁免，应单独评审、单独比较，不把新的地形机制与本轮候选捆绑。

## 两套补给语义，均不在本轮修改

旧Core：断供A乘0.5逐单位向上取整，M减1；前述全断供且无退路时D减半。隔离实验Core：有`expSupply`时，A取`ceil(模板A×attackFactor)`，M受`movementCap`限制；不再重复旧式A/M与围困D惩罚。`experiments/supply-exp-005/live.py:13–19`投影的债务因子为1/0.75/0.5，债务≥2时MP封顶1；行动支付可能进一步限制攻击因子。

因此研究中的“苏军1941年装备/组织不齐”只能作为模板所属情境，不能再把正在运行的补给损失重复塞进模板。骑兵未来接入还需要明确其补给类别，绝不能因为改名就免费获得低消耗。本轮没有修改或裁定SUPPLY-UX-020内容，也没有宣称核实线上版本。
