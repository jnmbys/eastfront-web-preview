# RULE-HISTORY-021｜历史依据与单位数值候选

研究日期：2026-10-01（Asia/Shanghai）。状态：**候选，未应用到运行规则，未做平衡验证**。

## 先回答两件事

**没有证据支持“猎兵师天然具有高于普通步兵师的通用战斗力”。** 固定基线中两者攻防实际上相同（5/5、4/4、3/3）；猎兵强在全地形多1MP、森林/丘陵无路移动减费，以及取消整场攻击的森林惩罚。这三层效果叠加，使它成为几乎没有代价的普通步兵升级。史料支持轻装两团制与特定任务适应性；不支持把名称当成精锐证书，也不支持这些精确游戏加成。

优先校准顺序：

1. **G-JAGER**：先削减通用优势，候选三档 `4/4/3 → 3/3/3 → 2/2/2`；暂沿用既有地形效果，不再叠加新特性。森林整场豁免仍可能过强，须单列规则问题。
2. **S-TANK / S-HEAVY / S-MOT**：先明确年代与单位尺度。1941年坦克师、后期坦克旅、重坦分遣队不能因都叫“单位”而当成等规模师。未定尺度前不强行给出统一降幅。
3. **G-MOT、S-ELITE**：分别去除“有卡车就多火力”和“名称精锐就永久高出67%”的默认假设；给出有完整损伤曲线的保守候选。
4. **S-INF**：德苏5:3不能被称为历史常数。保留为早期战役情境抽象；另列苏军防御+1的独立候选，不能与其他方案未经验证一并采用。

## 年代与尺度采用方式

仓库没有明确日历年份、每回合天数、每格公里数、单位层级。地图是 Strategic Reset F 抽象盆地，不应自动认作某次真实战役。研究以**1941年下半年东线**为工作假设：适于讨论轻骑兵扩编、机械化部队重组和德军轻步兵，但这不是已存在的剧本设定。

主力步兵/装甲暂按“师或师级战斗群”解释，支援单位按“独立支援群”解释；苏军后期坦克单位须明确是旅群还是师的残部。若项目最终选1942—43年，应重做苏军机动部队尺度与德苏差距，不能直接套本轮数值。猎兵1941年宜标“轻步兵（后称猎兵）”；正式改名年月需具体师档案复核，不凭后期名称倒推1941年的组织和战力。
