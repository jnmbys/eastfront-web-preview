# 苏军骑兵替换候选

## 主方案：两个普通步兵槽位一对一替换

以1941年下半年**小型轻骑兵师**为解释，取代初始 `S-I-15`、`S-I-16` 两个槽位，候选模板概念名 `S-CAV-L`、展示名“轻骑兵师”。保留槽位ID，不增加单位，也不伪造历史番号。选择尾部ID只是让差异容易审计；现有槽位无历史部队身份，不意味它们历史上曾改编。

|项目|当前|候选|
|---|---|---|
|两个槽位|S-I-15、S-I-16：S-INF|同ID，各换一个S-CAV-L|
|初始苏普通步兵|16|14|
|初始苏轻骑兵|0|2|
|苏初始全部单位|32|32|
|苏增援|13（含6普通步兵）|13，类型/时点原样|
|苏全程潜在单位数|45|45|
|德初始/全程潜在单位|26|26|
|双方全部潜在单位|71|71|
|三档A/D/M|每个3/3/3 → 2/2/3 → 1/1/2|每个**2/2/4 → 1/2/4 → 1/1/3**|
|每个最大步损|3|3（设计妥协，并非相同人力）|
|两个槽位满编A/D合计|6/6|4/4|

“不增总兵力”在本轮可核验的含义是单位数、增援槽位、最大步损总容量不增加；基线没有人数/装备字段，无法证明按真实人头严格守恒。候选明确比被替换步兵群更小，不把节余人力偷偷生成新单位。此处计数不代表抽象兵员相同。

## 装备与作战定位

H06的1941年概括区分较大的战前骑兵师与后期约3,400人的轻骑兵师。主方案取后者这一规模档，**并不声称已核准具体штат编号或精确实有装备数**。建议装备设定为：骑乘步枪兵为主体，轻重机枪、迫击炮、少量马挽/驮载火炮与反坦克兵器；无独立完整坦克团、无大规模装甲运输。具体炮数待师番号/月份确定后核验，不把战前骑兵师的坦克团“免费带入”。

H09的敌后任务和H11的下马攻击记录支持将机动与正面战力分开。M4表示行军、侧翼转移、填隙/追击的抽象机会；A/D较低主要代表小规模与较少重火力，不代表骑兵个人训练一定更差。对坚固阵地的持续正面进攻弱于完整步兵师；下马后仍是有机枪/迫击炮的战斗部队，不能做成只有马刀的装饰单位。

满编普通步兵M3、骑兵M4、摩托化M5，是为可玩性选择的等级，不是历史速度表。马匹需要饲料、休息、照料与补充；骑兵不获得无补给免疫。当前没有道路与越野分兵种速度系统，所以同一MP不能完美表示骑兵与汽车的真实差别；不在本轮引入天气机制。

## 候选旗标和实现边界

未来若采用：建议`isArmor=false`，无装甲突破/重点突击；`infantryCoordination=true`可解释下马协同，能免除己方装甲无步兵协同的复杂地形惩罚，但不新增苏军正协同列移。建议`exertsZoc=true`，遵守普通ZOC停步；`isSupport=false`、`canEntrench=false`、恢复成本1作为轻骑兵机动角色的初始设计提案。不能筑垒只是设计限制，不声称骑兵不会构筑阵地。

不继承JAGER的森林/丘陵减费与森林攻击豁免，也不继承RECON的ZOC穿越。骑兵不应同时得到M4、猎兵减费、侦察ZOC忽略和额外战斗加成。

当前`UnitType`没有CAVALRY。**这不是只改名字就能上线的配置变更**：新类型涉及Core类型/规则接缝、单位表、展现、AI与补给分类；均超出本轮范围。`MOTORIZED`在补给实验的普通移动费用集合中，不能借用其类型再声称骑兵已正确接入。未来实现须由相应负责人评审；本轮只记录依赖，不修改或接管SUPPLY-UX-020，也不替它决定饲料/维护费。

轻骑兵同样保留3步损与一份ZOC，会有“低A/D但适合吸收步损”的玩法风险。当前`maxDamageSteps`只允许1或3；不为本轮擅加2步损机制。若3步小师后来过于耐损，应在统一单位尺度议题下评审，不能在此伪称历史已支持。

## 互斥备选

|方案|替换槽位|数量与定位|适用条件|
|---|---|---|---|
|N2-A（首选）|S-I-15、S-I-16|2个轻骑兵，快于原普通步兵，火力较弱|抽象1941下半年初始编制；不声称真实改编|
|N2-B（机动部队重组类比）|S-MOT-02及T10摩托化增援`S-R-T10-G03-U02`|各一对一换为轻骑兵；其余不变|H10提供个案类比；但M4比被换摩托化M5**慢**，只能满足“比步兵快”，不能说所有被替换单位更快|
|N2-C（若选严格1941年6月）|仍为两个S-INF槽位，改为战前骑兵师/战斗群解释|暂定3/3/4 → 2/2/4 → 1/1/3，**不满足明显较低A/D**|战前骑兵含较多支援/装甲的类型与后期轻骑兵不等同，须先核具体师；若用户坚持低战力，改用后期设定更一致|

三个方案只能选其一；不能A+B额外放4个骑兵，也不能用一个步兵槽位拆成数个骑兵师来扩充棋子。1942—45年的骑兵军/骑兵机械化群也不是单个弱轻骑兵师，不能套用N2-A。
