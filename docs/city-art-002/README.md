## 实际画面

- 主城：公共大厅、广场与喷泉、街巷、紧凑住宅；站区：按真实铁路方向布置站房、站台和装卸院落。
- 工业区：工业地面、服务道路、预留槽位；住宅近郊：四组低密度庭院、小路、绿地和菜畦。建筑采用约10公里/格的符号化群落尺度，留出外围空地。
- 同城相邻区外缘连接，内部共有边不画墙。非相邻组团分别围合。低砖石墙、近郊细围栏、投影、门柱与真实道路/铁路/河流开口，不是防御设施。
- 工厂由永久 ID 单独绘制：空地、施工架/吊机、完整 F3 式屋顶墙面烟囱、封存标识。装饰地表不预画可用工厂。一条设施记录只对应一个实例；真实产能和数量未变。
- 新的近景屋顶接缝、窗门、站台、铺装、墙缝均为实际几何细节。图层在 FOW 下、单位/操作层下；不关闭雾或取消状态以求清晰。己方后方地区当前不在接触范围时仍显示原授权的「待确认」。

## 成本与限制

既有素材完整路径/尺寸/文件大小/哈希和新组件清单见 [ASSETS.json](ASSETS.json)。沿用项目既有 F3 程序化屋顶、墙面、投影方法，新增可组合原生矢量部件，**新增位图0字节/0请求**，没有新村庄贴图包。

实际跨远中近三档：32次地貌图片请求、32个唯一URL；50次解码缓存命中，32张解码图片共22,478,848字节（21.44MiB），上限32MiB/40项。当前挂载近景画布2561×2476=25,364,144字节；三档画布缓存合计39,458,788字节（37.63MiB），未放大全地图上限。可见城区最多16个、4ms让出执行片段，静态字符串缓存上限48项/2MiB，实测约1.00MiB。活跃解码租约安全释放后才可淘汰；预算是缓存驻留目标，不是整个浏览器/GPU进程内存硬上限。

远景先显示，细化显示「城区细节加载中」，保留可操作画面。旧全图近景地貌仍有明显构建成本（本次记录14.3秒；此前一次23.5秒），期间选兵已验证，不能称无卡顿或移动端性能达标。Canvas/解码/字符串数字分别统计，不包含DOM、临时解码副本、GPU纹理等。
