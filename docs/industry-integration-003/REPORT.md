# INDUSTRY-INTEGRATION-003 工业与补给联合验证

2026-10-02。研究交付，未实现运行系统、未部署。

**工业能增加兵力，但本实验中新增兵力和装备货运同时争用补给运输；延长到24回合也不会自动解决这个瓶颈。** 推荐保留立即扩军、扩产车间、运输与维修三类选择，并把预计到货时间、维护增量和可维持攻击规模一同展示。现有样本未发现跨条件始终最优的路线；这不是不存在最优策略的证明，也不是平衡验收。

本报告承接 [INDUSTRY-EXP-002](../industry-exp-002/REPORT.md)，只新增本目录的Markdown和JSON。主账采用 [RULE-VICTORY-024候选](https://github.com/jnmbys/eastfront-web-preview/blob/09bc1bde826b5b1ce6b6d84e084e12c392bdcca5/docs/rule-victory-024/REPORT.md) 的24个完整结算边界。当前运行规则仍是旧16回合首都胜利；没有把新Victory当作已上线规则。

## 实验起点与三种投资

**除明确引用的源码事实外，以下价格、数量、周期、阈值及算术结果均属于实验假设，不是史实或正式参数。** 一回合约一周仅沿用Victory-024设计候选；账本不依赖确定历史日期或地图尺寸。

三路共同起点：8支三阶步兵，其中2支各缺1阶；初始携行物资共24SP；可用人员60P；后方和前线成品装备均为0；投资额度12I一次性发放，后续无I/P收入。基本产量2E/结算，物资来源上限22SP/结算，装备与SP共用21单位运输能力。1E为一阶装备包，1P为一阶已训练人员包；I不是RP、CP或SP。

|路线|同样花12I买什么|建设与兑现|明确代价|
|---|---|---|---|
|A 立即扩军|后方急拨12E|E1进后方，仍受每轮4E装运上限；第一支额外新部队T3行动|没有后续增产；更多单位较早消耗维护与攻击物资|
|B 工业投资|一处后方扩产车间，增量2E/结算|经历3个建设边界，E4首次增产；相比不投资对照，T6首次多一支可行动单位|前期少兵；后期人员、装运、来源可能使成品积压|
|C 运输维修|8I运输节点＋4I维修设施|E3起运力21→25；每E最多将0.5E真实残骸修复为成品|不增加物资来源；没有A的急拨装备，前期兵少|

人员、装备与消耗性补给分账：新编一支用3E＋3P，最多一支/轮；恢复一阶用1E＋1P，最多一支/轮，并放弃该单位本轮攻击。每支单位每E维护1SP，每次步兵攻击最多消费1SP。仓库成品本身不收单位维护；装运成品才占运力，编成部队才增加维护。当前Core仍用既有RP恢复，本实验没有改规则或同时加收RP。

C维修只提高残骸转回装备的能力，**不提高每轮恢复单位上限**。回收须消耗有限残骸、不返还人员；本地回收免长途运输是有利假设，尚未验证战场回收资格。

B计划名义产量90E，但仓满会少生产，实际83E。期末24E成品中23E仍在后方；它们不等于可用的8支新师，人员仅余1P且装运已受限。C保存了更长的满效攻击窗口，但从T17也开始减效，没有无限持续进攻。

## 工业实力与后勤压力的因果链

B相对D不投资对照，期末20对15支单位，累计维护375对276SP，满效机会67对143；相对A，期末只多1支、累计多付15SP维护，却少25SP攻击消费。生产扩大了可装备规模，也挤占了行动供给，并非只给无代价加成。

在不再扩编的反事实中，四路都维持8支、维护192SP、169次满效机会和辅助攻值820；B只是多存装备。这说明“更多装备→更多维护”必须经过**实际扩编或不同维护等级的装备上装**；仓储成品本身不自动吃维护。本账本只有同类步兵，尚未检验装甲升级导致的额外维护。

给定稳定兵力N、每轮恢复休整r人、装备发运eE，全部其余单位满效攻击的长期近似需求为：
- 物资来源至少 N＋(N−r) SP；
- 共用运输至少 e＋N＋(N−r)；
- 还须逐单位收到物资，并满足战术合法性与人员/装备条件。

初始携行储备能暂时突破这个长期上限。以r=1估算，基础走廊发2E时，持续满攻约支持10支；B每轮发4E时约支持9支；C发2E且来源仍22SP时约支持11支。它们是稳定态预算提示，不是新增兵力硬上限；玩家可以轮换攻击、屯物资、减少发运或承担减效。

主表全部维护足额、D=0、没有后勤步损。**攻击储备不足与维护短缺是两件事。** 目标运输压力包含把储备补至上限的愿望，B峰值4.00也不等于当轮维护欠付400%。

## 回收时间与永远最佳路线检查

B的增量名义产出在E9累计12E，等于A急拨；最早T10才能使用这批追平的产出，且仍受调运、编成和人员限制。B可行动单位直到T12才首次多于A。E9是实物数量追平，不是资金回收或胜利收益追平。

|同条件样本|观察结果|解释|
|---|---|---|
|主场景24回合|B兵力最多；C满效机会与辅助攻值最高；A前8轮辅助攻值366，高于B326/C306|同一局内不同时间和任务会改变选择|
|来源40SP、运力44|A/B/C满效机会326/363/279；B辅助攻值1775领先|有足够后勤时工业能兑现后期攻击规模；但B人员耗尽，恢复18阶、积压6阶|
|运力只有15|A/B/C满效机会23/37/83；C期末18支，另两路14支|运输瓶颈下修通物流比继续产装备更有效|
|来源只有6SP|B与D同为7支、16满效＋144减效、辅助攻值446|提高产量无法替代物资来源；支出12I没有获得这些战力指标改善|
|每轮最多8个攻击目标|A/B/C满效机会60/69/189|狭窄战线使额外部队缺少攻击位置，却仍占维护|
|基本产量0.5E|A/B/C辅助攻值1101/1080/804；B兵力17最多；C恢复22阶最多|抢先形成部队、晚期规模、老部队恢复仍是不同价值|
|全部禁止扩编|四路攻击与维护相同，B库存最多|无装备转换需求时投资无作战回报|

D拥有同样12I但不花，不是等支出主路线。运输/维修拆分组保留未用投资：只运输花8I时，C有205次满效机会但只15支；完整C有158次但18支。回收装备继续被自动用于扩军，会反过来压低满效次数；组件不是无条件相加。

独立短期重算H=8/12/16/20/24均执行各自最后E，统一政策下B的累计辅助攻值未超过A；后勤充足的24回合则B超过A。这既否定“长局工业必胜”，也不支持“工业永远不值”。提前终局不是把24回合结果的库存打折；要看结束前已到达、已部署并改变局面的成果。

这些是13组共同条件、52次账本推演及参数扫描的反例，不含敌方自适应行动或混合投资优化，不能证明策略空间没有支配路线。

|项目|下一轮推荐试验范围|理由与限制|

|维修回收|0.5E/结算作为候选，上限受残骸约束|0/0.5/1E扫描可改变扩军节奏；不能承诺同时提高恢复上限|

|新编政策|增加“预留恢复所需人员和装备”与“暂停扩编”选择|充足后勤下B也会耗尽P；本轮只测固定先修后编，尚未标定应预留多少|

玩家的三个具体决策是：是否牺牲T3—T8的增援抢先投产；是继续组新部队，还是把成品、人员和物资留给现有部队；下一笔投资应解除来源、装运、战区接收、恢复材料中的哪个瓶颈。不能只给一个“工业收益率”数字。界面至少显示建设完成E、预计首个可用T、在途/仓储分离、每支新部队维护增量、当前来源与线路余量、剩余人员和终局前可用轮数。

## 与Victory的关系及最大风险

完整衔接见 [VICTORY.md](VICTORY.md)。Victory-024候选不把工厂、库存和产量直接换VP；工业只能通过实际部队行动、节点控制和恢复组织损失发挥作用。所有路线都可能因较早结束而失去计划中的后期收益。不能给B强制保底24轮。

**最大风险是把固定物流不足造成的“兵多但打不动”误判为工业战略已经平衡。** 本账本没有两个阵营的真实控制争夺，也没有现行多路径补给优化器；自动扩编、平均抬升库存和无限目标假设，会显著影响路线排序。Victory-024还提示其参考补给配置自身存在供需不足，不能把这里的22SP单走廊假设当作正式战役参数。

另外三个待验证风险：
- 纯减效大军可能靠占地、堵路或低成本攻击优于少量满效部队；本轮没有CRT、堆叠与地图空间，不能排除此支配策略。
- C免费本地回收、固定战损不响应攻击次数、前线随时可恢复均偏乐观；工业后方与战区节点的位置、控制和运输距离需后续真实场景。
- Victory中的新编稀释兵力损失比例、节点失守同时影响VP/物流/压力，以及末轮发运挤占维护都可能产生意外激励；不能以账本守恒代替这些检查。

实现后须测量：单个E新增状态与日志字节、多人同步增量、回放确定性；源/边/单位数量增加时求解p50/p95/最坏耗时、内存及3秒超时率；重复请求和断线重试是否重复产出/计VP；生产、货运、维护、战损、胜利同一事务失败是否整体回滚。使用有限建设队列和一次E结算有利于控制工作量，但不保证不会卡。
