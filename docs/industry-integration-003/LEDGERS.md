# INDUSTRY-INTEGRATION-003 逐回合联合账本

所有数字均为实验假设下的离线计算。主表采用24个结算边界E1—E24，不能与002省略最后E的表直接相减。完整逐单位流水见 [LEDGER_DATA.json](LEDGER_DATA.json)，方法见 [METHOD.md](METHOD.md)。

N是本轮行动时的存活单位数；库存为本E结束后成品装备（后方/前线/在途），不含已装备部队或残骸。M是本E维护需求，含本轮整编后在集结地开始维护的新单位；所以可能比N多1。SP实收不是攻击消费，也不能转成成品。攻击列为满效/减效的单位参与机会，假定每人有独立合法目标，不是Core命令次数。

运载列为实用/上限；压力是希望把携行储备补满的目标货量/上限，非维护欠账。恢复列为材料与资格允许的阶数/实际恢复阶数，每单位至多一阶、总上限一阶；“伤阶”为E末未恢复积压。P为人员余量。主表三路每E维护均足额、D均为0、死亡均为0；每个非初始伤口恢复后重获己方行动的等待均为2个回合编号间隔（含下一行动窗口），不能理解成同轮恢复后再攻击。
