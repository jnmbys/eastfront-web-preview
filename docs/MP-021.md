## 时间口径与盲区

客户端 send 是调用发送时点；callback 是 JS 消息回调，已晚于浏览器底层 WS 解压/调度。parsed 是应用 JSON 解析完成，query-applied 是通过 requestId、版本与草稿检查后应用合法模型。合法选项就绪及允许提交沿用原门禁，不是新定义，也不是像素绘制完成。原四类时点和同步渲染区间保留在 action 报告中。

服务端 receive 是 WS JS 回调入口；dispatch 包含转换、解析和分发，查询计算包括已授权模型、强制决策和摘要；serialize 到 send 为序列化/交给接口。write callback 只表示 ws 本地压缩/写出回调完成，**不是对方收到、不是网络 ACK**。嵌套 query-build 和内部子段不能重复相加。

没有观察到应用层查询队列；`queuedAt=null` 表示没有该队列的可测时间点，不能把 JS 回调前排队视为零。跨设备不减绝对时间，只对照各自持续时间。客户端 send→callback 减服务端 receive→handoff 后，剩余仍包含浏览器/服务端回调前等待、压缩/写队列、代理与网络等，**不称纯网络 RTT**。本轮没有拆开公网代理逐段耗时或底层事件循环等待。
