## 2. 城市等级与VP：先分角色，再分空间

| 规划层级 | 建议数量 | 表现与战略职责候选 |
| --- | ---: | --- |
| 战略中心 | 1个城市群 | 保持现有两核心＋一外围；连续街区，但三格不能被误算成三个独立首都 |
| 区域中心 | 从6座普通城市中研究2–3座 | 较完整街区、转运/工业候选；不是新增地形类型或已指定城市名单 |
| 地方节点 | 剩余3–4座 | 较小院落与交通入口，给周围平原和单位留空间 |

区域＋地方必须恰为6座；等级是视觉/战略角色草案，正式CITY/MAIN_CITY/OUTER_CITY不变。
推荐首轮比较**6–7个VP目标群**：首都群1个，加5–6个普通城市群；是否计入首都外围、是否拆分占领判定，交规则设计决定。不给工厂、每座桥、每个出口默认附加VP，避免一地多次计分和满图目标标记。

不同城市群最近的六边形距离为6–7格。对未来同类随机图，可先以**6–9格最近邻距离为软目标，低于5格提示复核**；同一首都群内部不套这个间距。这个区间只是参照当前分布，不能换算成移动回合或补给半径。

## 3. 工业空间：4–6群起步，2–3格是构图预算

| 工业群数量假设 | 每群2–3格的毛预留 | 占640格 | 用法 |
| --- | ---: | ---: | --- |
| 4 | 8–12格 | 1.25%–1.875% | 推荐先验证的低密度方案 |
| 6 | 12–18格 | 1.875%–2.8125% | 推荐范围上沿；需逐群证明铁路与单位净空可兼容 |
| 8 | 16–24格 | 2.5%–3.75% | 拥挤压力算例，不是增加工业的目标 |

预留并非新工业地形、禁止单位进入的占格规则，也不是从640格之外再加格。设施核心、装卸/铁路侧、可选集结侧形成相邻2–3格组；最终工业类型、数量和真实尺度须先由工业设计确定。
表中是毛预算。与城市、站场或仓库共用时，实际占用按**格子集合的并集**统计，不把VP数、站场数、工业数、补给数直接相加；同格分配仍需检查多角色冲突，不能靠重叠记账证明放得下。

**最小净空口径：**沿用017的38×20世界单位内容框；018暂加每侧2缓冲，得到42×24研究框。它不是最终工厂最小尺寸，未含定稿烟囱、阴影和交互图标。现有单位中心净空68×68，标签20×10（中心下方29），交通中心线两侧各7；单格外包约72.75×84。

018几何结果说明：空格可容纳该研究框；同格保留中心68×68单位净空时放不下；水平铁路穿中心时，42×24研究框也放不下。这只覆盖指定矩形、标签和轨向，不能据此否定所有斜向站场，但足以否定“把工厂塞进每个交通/单位格”的默认方案。

每个工业候选必须提交以下空间记录，再进入素材制作：

1. 设施核心的包围范围与标签位置，以及空置、单单位、双单位三种覆盖策略。
2. 对应真实铁路端口与路径；相邻铁路并不自动代表装卸接通，桥头必须使用真实桥。
3. 至少2个相邻的非湖泊接近/操作候选格；3格方案包含1个专门测试集结显示的格。它们是否可通行仍由规则确认，不能只凭地形名称验收。
4. 不截断既有道路、铁路入口或桥头；当前单位位置不动。无解时降为较小视觉角色或拒绝候选，不能移单位、挪标签语义或改河路凑位置。

原则上重型工厂、大片站场与双单位牌不同时争夺同一格中心。未来可以研究“设施烘焙地面＋单位优先＋侧栏说明”，但固定015尚未实现这套工业交互；AC10未选中辨识不足仍保留，不能把屋顶避让当成辨识已解决。

## 4. 铁路与补给密度：保留主线，控制功能标记

推荐首轮按**6–8处有明确功能的站场/转运地点**研究，其中2–3处承担较大区域转运，其余为小站或工业装卸候选。这个数量包括工业接轨站场；不再给4–6个工业群各额外加一座站。与城市群错位的站场可以留在既有非城市格，不能因此改成CITY。

对未来同尺度生成图，可把相邻功能站点的铁路最短路**6–10边**作为软目标；超过12边触发玩法复核，而非自动补站。当前D10的14边段是明确待复核样例，本轮原样保留。不足3边且角色相同的两个站应优先合并视觉说明；首都内部、换线咽喉或桥头可作为有理由的例外。度数≥3仅提供交汇候选，二向格也可以有站，铁路度数不代表吞吐量。

补给建议先比较**3–4处内陆仓储/转运角色**，优先与首都或区域站场共用；这是未来仓库体系的设计预算，**不替换现有补给源或六个边界端口**。工厂负责生产、仓库负责储运、站场负责交通、VP负责目标评价，功能不能从屋顶外观互相推断。
是否需要仓库、补给半径、容量、损坏与控制规则都未定，不能承诺3–4处可以覆盖640格。

主干与区域中心优先研究两条拓扑上不同的接近路径；明确设计为咽喉的桥/边界支线允许单路径，但要标注单点中断风险。路径检查先在无损图上做，再由规则Worker检验战时状态。本轮不增边、不修铁路，也不把静态连通当供给通过。

## 5. 单位堆叠与战场可读性

固定基线Core的堆叠上限为2；这里只把它作为现有显示兼容要求，不制定新规则。58枚展示单位在全图平均每100格9.06枚，平均值掩盖铁路咽喉、工厂和城镇的局部拥挤。

| 情况 | 必须保留 | 后续验收口径 |
| --- | --- | --- |
| 0枚单位 | 城市/工业角色可识别，线路入口完整 | 300%看街区与用途、500%看边缘；当前AC10是已知欠项 |
| 1枚单位 | 中心净空、完整命中区、格标签 | 不因设施覆盖改变选格/选单位语义 |
| 2枚单位 | 双牌错位、两枚均可选择、堆叠消歧入口 | 从两种选择顺序和未选中状态检查；不能只测上层牌 |
| 邻接拥堵 | 工业群及两侧接近格同时放2枚，共最多6枚的局部显示压力样例 | 只作未来独立夹具；本轮未创建或声称验收 |

现有单牌约47.88、双牌各37.8世界单位，双牌错位(-6.5,-6)/(6.5,7)。世界单位不是手机CSS像素。不能通过缩小单位来腾出屋顶空间，也不能据“640×2”推导可用军队规模。未来若要求3枚以上同格，必须重新评审显示与交互，不能沿用现有双牌布局直接叠加。
工业核心旁的操作空间可与平原走廊共用，但不得全部填满院落装饰。未来随机图应检查跨区域机动路径和桥头两侧可操作区域，不强求每个局部都对称或绕行。

## 6. 未来随机地图模板：先拓扑后构图

本节是模板契约草案，不是新生成器、真实坐标清单或素材生产任务。

| 模板 | 局部组织/端口 | 首要限制 |
| --- | --- | --- |
| 首都群 | 2核心＋1外围；铁路/道路接入；内部分区 | 一个战略群，VP和占领判定不得按绘制格自动拆分 |
| 区域城镇 | 城镇核心＋邻接候选区；转运角色可选 | 全图总数与城市等级预算一致，避免所有功能堆一格 |
| 地方城镇 | 小街区与院落、一个清楚入口 | 优先留平原与单位空间，不按屋顶数量赋予规则等级 |
| 工业群 | 2–3格视觉预留；核心、装卸侧、可选集结侧 | 真实铁路可达；42×24只是暂定研究框；0/1/2单位覆盖检查 |
| 仓储/转运 | 可附属既有城镇/站场；独立设施大小待定 | 不自动成为补给源，不复用工厂外观假装完成分类 |
| 铁路交汇/站场 | 真实2/3/4向端口；建筑规模独立于度数 | 端口逐一配对；不增加不存在的支线 |
| 桥头/河岸 | 成对河岸、唯一登记跨河边、接近侧留白 | 不添加渡口；桥头空地不等同额外跨河边 |
| 平原机动盆地/绕行廊道 | 连接相邻战略区域的可读开阔段 | 避免工业装饰封死视觉走廊；通行仍由规则判定 |
| 林缘/山脚肩部 | 邻接地形驱动的疏密、接触阴影与材质过渡 | 不模糊真实地形类型，不削平山体体积 |
| 地图边界端口 | 与场景约定的外部铁路端口连接 | 当前三西三东是本场景事实，未来阵营/出口数须由场景确定 |

每个模板至少描述：稳定ID与美术种子、角色集合、相对格范围、允许地形及邻接、铁路/道路/河流端口、桥字段、设施和标签包围框、单位净空、0/1/2枚覆盖策略、可变组合、全图数量预算、失败原因。种子只驱动视觉变化，不消耗Core RNG。
拓扑允许的旋转与贴图旋转是两回事；烘焙光照素材不能盲目镜像/旋转造成光向冲突。现有按坐标取模的布局有12列重复周期，未来应研究稳定ID＋邻接选型；本轮不改布局算法，也不新增图片。

建议生成/验证顺序：

1. 固定640个格、场景端口、地形/河网契约和战略角色预算，先明确距离与时间尺度。
2. 分配城市群与VP角色，检查群间距离、阵营接近机会和目标集中度；不据美术直接决定VP权重。
3. 建立权威铁路/道路与跨河连接，校验边相邻、双向一致及桥字段；功能站点与支路一起统计。
4. 给工业/仓储分配候选组，按格集合并集结算空间；没有足够净空或铁路路径就拒绝，不扩图凑数。
5. 按邻接铺设已有地表、林缘、山脚与屋顶组合；地貌读法优先于装饰。检查视觉重复与统一光向。
6. 规则Worker验证通行、控制、补给、胜利和初始兵力；美术验证中景识别、标签、双单位与选择。

未来应把几何/连接错误作为硬失败，把6–9格城市间距、6–10边站距和数量区间作为可解释的软约束。现有地图不因未满足某条草案而被自动改写。允许咽喉、非对称场景和复杂战况，但例外必须有场景设计理由。
