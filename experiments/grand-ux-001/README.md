先维护→按军队优先级自动装备配送→储备。实际铁路格×载重消耗火车工作量，末端距离/地形消耗卡车工作量。每E原子完成后方→预约→在途→站场→部队待用交接，不持有跨E在途副本；下一T装填缺额，恢复的一步装备另留待用。部队持有卡车和独占运输池是不同实物。产线优先级用于同需求下选择供货工厂。无通路/运力/库存则明确等待。
