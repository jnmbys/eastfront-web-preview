## 矛盾在哪里

数值沿用原求解器的整数q口径（1q为四分之一SP）；货运LQ占用对应q容量槽，不产生SP库存。

|rail:B10~C10|40|32|8|32|

008完整计划冻结时GH2没有余量。009允许重选后，仍存在一个**不依赖求解器结论的约束矛盾**：

1. 保留当前维护，需要对15个缺料德军单位净配送58。原完整合法路线集合中，这15个单位只能由GH1或GH2配送；GH3没有通向它们的合格末端路线。
2. GH1期初库存为0，A5无其他铁路卸载输入，G-A5同格来源上限32。由原`rail balance:A5`、`hub:GH1`、`source:G-A5`三行可得GH1最多配送32，因此GH2至少承担26。
3. GH2可用的最便宜目的地：G-PZ-03/04合计最多11、单位W成本3；G-I-08/09及G-J-01/02合计最多12、单位W成本4。其余必需配送若走GH2，成本至少5。各上界来自这些单位固定净维护配送行，不是新参数。
4. 因此GH2所需W至少为`5×26 − (5−3)×11 − (5−4)×12 = 96`，但扣除材料装卸后只剩88，矛盾8。该证明对连续放松也成立。

`RESULT.json.infeasibilityProof`提供对应单位、合法变量、行名和算式；`certificate`完整保留93个变量和156行矩阵、上下界与整数标记。无可行原始解，所以变量`value`及替代库存为`null`，不把“无解”写成0库存或虚构流量。`null`约束界表示该方向无穷界。

008对G-I-01和G-PZ-01的额外储备补充分别为4、8，实际由**GH3**配送，W成本均为8。取消它们不会释放GH2。GH1的瓶颈是可得到的SP，不是只看其W余量就能让它接走更多维护。
