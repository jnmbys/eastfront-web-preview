# MP-022 通信接缝（供 GRAND-PLAY-001 接入）

当前固定底座 e008340a69304529ebab2f336938dba993366f34；CITY 真实接口验证，不是新连续战役验收。独立模块位于 experiments/mp-022，不改旧服务4197—4199及4210。新玩法交付后必须固定完整SHA再接入，不读取移动中的工作文件。

- 一个权威实例及其已有事务/回执/存档负责所有正式结果。通信不存第二套经济账本。请求至少含 instanceId、requestId、seat内单调commandSeq、kind、payload、依赖。重试复用整个原信封；receipt同时保存命令身份、接受/拒绝、应用版本、模拟时点与服务器单调时间。保存/加载请一并保存回执与seat顺序游标；恢复会话代数不作为业务ID。
- 适配器暴露 `id / revision / submit(seat,envelope) / view(seat,selection) / tick()`。submit必须原子提交且返回现有回执。kind和payload由玩法权威定义；通信只校验身份、顺序、尺寸与投递，不复制规则。CITY暂支持MOVE、PHASE、BUILD、OFFICER、PAUSE；这些不应强塞进新玩法。
- 新时钟推进完全属于玩法：tick由服务器调度，浏览器无需逐步发送；通信以独立推送节拍采样授权视图。CITY tick只调用已有军官执行器，不推进旧阶段，不声称提供共同战役时间。
- 真实依赖由权威检查：部队控制/命令版本、共享资源、待决冲突等。不能用每tick增长的总revision一票拒绝所有旧命令。CITY单元依赖只含本方可见部队状态与公开阶段；执行前再交原合法性判断。经济命令保留本方资源依赖。
- `view(seat,selection)`必须先完成FOW授权，包括删除/失去可见性；通信只对这个结果作差量。地图静态数据首包，动态实体按永久ID。差量含instanceId、connectionEpoch、stream、baseViewVersion、viewVersion、remove/set；基准不符请求完整授权视图。当前选中对象的必要合法选项随推送带回，未知选中对象仍需查询，不复用旧版合法菜单。
- 慢连接只影响该seat推送；R1每连接最多8个未确认状态；差量基于上一份已入FIFO发送队列的授权视图，窗口满时只保留dirty标志，释放后采样最新状态。业务结果保留在权威回执直到客户端确认，不能随状态合并丢掉。队列/消息/回执均有上限，达到上限明确拒绝新命令或断开并恢复，禁止静默淘汰未确认结果。
- 一方断线：已接受任务继续由服务器执行；未接受不执行。同一seat重连替换旧连接代数，旧回调不覆盖新状态。CITY进程重启会创建新instanceId，旧信封明确拒绝；不是跨重启存档。新玩法存档须复用上述原权威回执，不能只保存画面。

本轮不新增公网入口、不迁移服务；延迟夹具保持每条WebSocket连接双向各自FIFO，跨连接迟到另测。完成后报告适配器限制与实际浏览器入口。


## R1 暂停与推送约定

- PAUSE payload 使用 groupId（instanceId + seat + 固定编组ID），dependencies.commandGeneration 指明已安装命令代次。校验当前席位授权映射、成员 controllerId 和阵营；不比较位置、库存、单位摘要。重新安装命令或改变成员时，原编组与目标编组的代次均递增。失败配置回滚代次及编组；未来控制权转移、编组替换、恢复存档也必须保持永久ID和代次约束，不能复用旧代次。
- 暂停与军官执行共用适配器串行权威队列。已开始的军官事务先结束；PAUSE随后提交，不回滚既有结果。提交后后续tick看到paused，不启动该编组新动作。operation和有界诊断trace记录开始/结束顺序；它们不是业务账本。原requestId重试返回原receipt。
- STATE窗口8；baseViewVersion链依赖已发送前包。VIEW_ACK须带stream；只接受当前stream窗口中实际存在的版本，可累计确认此前包。RESYNC须带当前stream；重建stream并发一份完整**授权**视图，旧stream ACK不能释放新窗口。客户端缺基准时仅请求一次恢复，忽略后续差量直到full；同连接版本仍递增，重连接靠connectionEpoch隔离。
- 窗口满仅合并尚未生成的视图，不丢已发送差量。RESULT独立发送，沿用原权威receipts；连接超限关闭，重连按原ID补投并恢复回执。一个未确认视图超过15秒关闭该连接；每方向128条/2MiB队列、单连接socket缓冲2MiB、权威排队32、原回执4096上限保留。慢席位的状态ACK不阻塞另一席位；共享权威事务仍有实际计算成本。
- 每连接只保留一份最后发送的授权视图与最多8条版本/时间元数据，不保存8份完整世界。按删除路径同步失去可见性，授权过滤仍在diff之前。静态地图仅首包/重连/缺基准full发送。
- age界面为“状态年龄下界（不含传输）”：服务端从授权视图入队到调用ws.send的持续时间 + 客户端应用后本地持有时间。排除了线路、浏览器回调/解析与生成前的时间，不能称端到端年龄。updateIntervalMs只在客户端单调时钟内相减。state-dispatched只代表调用ws.send，不代表到达。
- 本次仍是旧CITY内存实例；没有接入GRAND-PLAY共同时间或跨重启存档。R1协议只配套本分支客户端；4210原候选保持运行旧协议。
