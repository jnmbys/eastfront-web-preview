本机试玩：http://127.0.0.1:4227/ 。进入共同战役即可继续；独立服务保持运行，正常起点已推进15游戏分钟并暂停。不是公网入口。

## 规则与操作
- 当前视野＝本阵营实际控制地块＋原有侦察；控制来自权威 hex.control。德苏同规则，军官与苏军AI使用同一授权入口。
- 后方无需驻军。敌方、未控制和中立地块不会凭空点亮；基础地图地形仍沿用已有公开地图。
- 领土视野识别普通敌军与设施，但不公开敌方连续战役的精确人员、组织、装备和库存。设施可见不等于服务可用。
- 占领立即点亮；失守后仍在侦察范围内则保持实时，无侦察则记录“已失守，现控制待确认”。只保存当时已见事实及游戏时间，不更新后续隐藏活动。
- 点底栏“视野”查看规则、历史地点与历史敌情，点地点可定位。灰色虚线/斜纹是历史地点，不能当作当前控制边界；敌情文字明确写“曾见”和时间。
- 城区逐格授权，主城换旗不会自动揭示敌守站区/工业区。没有改变城区合法转移规则。
- 时间、部队、军官、战斗、生产及配送仍使用原操作。离开前暂停并保存。

## 准确启停
已启动时无需重复执行。关闭前网页保存，再在本源码目录执行：
`powershell -ExecutionPolicy Bypass -File experiments/grand-vision-001/stop.ps1`
只停止4227且命令行属于本候选的进程，不批量结束Node。
重新启动：`powershell -ExecutionPolicy Bypass -File experiments/grand-vision-001/start.ps1`。
若尚未构建，先 `node ai/local/build.mjs`；启动脚本拒绝占用已监听端口。
