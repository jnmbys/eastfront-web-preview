# GRAND-UI-001 操作与回退

本机入口：http://127.0.0.1:4226/ 。已保持服务运行，进入共同战役即可继续。不是公网部署。

## 五分钟操作
1. 默认地图只保留资源时间栏、军团栏与部队。点击下方军团查看任务；◎单独定位，Ⅱ暂停该军团。世界时间继续时，敌军仍行动。
2. 军团侧栏选择任务、地图目标和风险，再点“委托军团执行”。下方“指定前沿”逐格添加最多8个相连地块，提交后才是执行授权。直属部队不自动加入。
3. 点地图堆叠，展开后逐队选兵；绿条组织，金条人员。人员数字四舍五入为整数，比例由原始值计算。
4. 点交战圆标看敌我对阵。点己方部队或“选择可参战部队”，直接攻击或支援。需要撤回时先在地图选撤回位置，再点对应部队撤向目标。接管不撤销已经发生的战果。
5. 点顶部预算、装备或车辆打开实际生产运输；点待办查看低组织、缺装备或运输受阻，继续进入部队或管理面板。
6. 离开前暂停世界并保存；设置中加载默认暂停。设置中保留连接恢复、原操作工具；城市入口保留生产管理。

## 启停
源码根目录先 `node ai/local/build.mjs`；启动 `powershell -ExecutionPolicy Bypass -File experiments/grand-ui-001/start.ps1`。
正常交付不必再启动。脚本拒绝覆盖已有4226监听。
关闭前在网页暂停并保存，再运行 `powershell -ExecutionPolicy Bypass -File experiments/grand-ui-001/stop.ps1`，只停止命令行匹配本候选的4226进程。
存档：`%LOCALAPPDATA%/EastfrontSaves/grand-ui-001/campaign.json`；日志在同目录 stdout.log、stderr.log。
原4225服务、原存档和进度没有修改。回退访问 http://127.0.0.1:4225/ ，或从固定基线990d19a8a5a28357061ad0b45840af2497f68ae1建立独立工作目录。

## 范围
本规则仍是德军玩家、苏军AI，现有三个军团。没有无限战线、独立预备队结算或新战斗规则。
没有新增全域领土记忆；只画当前授权控制边界，未知一侧以情报边缘表达，城市沿用已有最后已知/待确认显示。没有把未知填成敌方。
浏览器验证使用既有正常战役存档的T12片段，当前本候选留在T15暂停；可继续指挥。未开展新一轮完整战役或真人趣味性采样。
