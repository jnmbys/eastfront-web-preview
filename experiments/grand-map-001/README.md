# GRAND-MAP-001 — 控制区、前沿与真实持续战斗

基线 `f18bb8328215c73a918604f5917c24ba11e6be25`。独立分支 `grand-map-001-control-battles`。

## 打开与操作

入口 **http://127.0.0.1:4221/**。进入共同战役即可继续本候选保存的暂停战线。
同入口 `?client=a` / `?client=b` 是同一德军统帅的两个协同端；苏军仍由现有公平 AI 控制，并非两个可互换阵营客户端。

1. 地图蓝灰为己方、赭红为敌方、灰为已确认中立。实线仅表示不同已知控制方的交界；点线是视野边缘，对侧未知。地块归属空白不等于敌军。
2. 点击军团标记或操作台的军团列表，指定任务和目标。地图金虚线是计划，不是已完成的推进。
3. 给军团指定地段：从地图指定目标 → 展开“指定前沿” → 把目标加入前沿；重复添加至多八个相连地块 → 按当前任务委托。普通地图标记仍不构成授权。可解除地段或暂停军团。
4. “继续时间”让双方共同作战。气泡中的“攻”“守”“↔”“↶”“终”分别表示我方进攻、防守、双方投入、发生撤退、结束；数字是已实际交战时间，绝非倒计时或胜率。
5. 多场接近时点击聚合气泡展开实际战斗；也可使用战斗列表。详情显示授权参战信息，敌方实时组织度、人员、库存、装备缺额为未知。装备显示持有/满编需求。
6. 详情可接管参战己方单位、撤向事先选择的地图目标，或让地图选中的另一己方单位增援。仍由原权威命令裁决；无安全撤退或胜利保证。暂停军官不停止敌方攻击；暂停世界才停止双方结算。
7. 暂停并保存后可关闭服务。重新启动或页面加载存档均默认暂停，旧请求不能重放。结束气泡最多展示两个模拟步或八秒，随后仅在最近20场记录中显示。

## 启动、关闭、回退

已启动的服务保持运行。若以后自行重启，在本工作目录执行 `powershell -ExecutionPolicy Bypass -File experiments/grand-map-001/start.ps1`；关闭只执行同目录的 `stop.ps1`。关闭脚本校验进程起始时间和完整脚本路径，不批量结束 Node。

本候选磁盘存档：`%LOCALAPPDATA%/EastfrontSaves/grand-map-001/campaign.json`；启动日志：`%LOCALAPPDATA%/EastfrontPreview/grandmap001.out.log` / `.err.log`。退出网页不结束世界，离开前请暂停和保存。

回退入口 **http://127.0.0.1:4220/**，原服务、独立存档和内存没有修改。原候选分支和固定 SHA 保留。4221只监听127.0.0.1，不是公网部署。

## 实际接入与规则边界

- 控制来自原 `state.hexes[].control`，经 `derivePlayerView` 的 `identifiedHexKeys` 授权。城市继续使用 CITY 原附属区转移，未添加半径吞并。未扩大视野或利用边界披露隐藏单位。
- 地图使用同一授权完整视图：MP-022-R1 先合并差量。只给相邻不同控制状态画公共边，不平滑狭窄通路和小块区域；同方内部没有粗边。已知城市附属区争夺另有文字，部分过期信息仍注明待确认。
- 战斗 episode ID 与原 pair 分离，脱离后再次接触产生新 ID；活动和结束记录随权威时钟保存。DTO 只投射当前可识别参战对象，历史保存当时已授权事实。敌方私人能力不下发。保留静态地图、城区和活动气泡宿主，按键更新对象。
- 前沿最多8个连通非湖泊公开格。每步仅以本方授权视图，将已有委托且非直属的活单位按地段负载、距离、稳定编号分配；优先均分再就近。沿用已有400节点路线预算、堆叠、风险、补给和停止条件。守备覆盖目标邻格，推进到分配点；不向授权地段之外自动延伸或追踪隐藏敌军。无法覆盖和未到位会显示，详细原因沿用真实部队报告。
- 新前沿功能只为当前选中军团突出任务，不声称已具有任意形状自动战线或自动突破优化。直属单位绝不自动编入。
- 没有修改伤害、RNG、时间、生产、配送或城市结算。新增 battle initiators 仅记录现有实际意图。森林/城区的1.25承伤除数作用于每个目标所在格；河流目前仅影响通行与耗时，无额外渡河战斗系数。资料不足统一标“态势未知”。
- 真实控制权本身存在中立地块与窄条，图层不会为了看起来像国家版图而补齐。连续战斗没有旧ZOC停步，战术图层因此明确称“已知敌邻接”。
