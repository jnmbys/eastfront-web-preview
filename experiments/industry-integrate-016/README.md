```powershell
python experiments/industry-integrate-016/prepare.py
python experiments/industry-integrate-016/run.py
python experiments/industry-integrate-016/verify.py
python experiments/industry-integrate-016/report.py
```

本机所用Python为原项目`.venv/Scripts/python.exe`。每条命令在新进程运行；同一进程不允许重新创建同一主实例。复跑会重写016自己的证据文件，时间字段及依赖它的TRACE字节摘要可能变化，原始依赖文件不动。

## 只读前端交接

`Transactions.view()`或`view.export_view(fullRoot)`返回独立JSON对象，schema为`industry-016-view.v1`。这不是状态导入、报价授权或写库存接口。视图修改不影响根；重复导出不改变库存、预算、回执、revision或RNG。

| 字段 | 含义 |
|---|---|
| `rootRevision/gameRevision/materialRevision` | 完整根、原游戏、016联合材料版本；照管付款不改变实物材料版本 |
| `equipmentBudget/personnelBudget` | 两套原账户；装备账户新增`careTransferOutI`，不是新增拨款 |
| `care` | 照管转账/支出、原P绑定、截止E9、不可退及失效状态 |
| `materials` | 原P包和E2批次的唯一实物分账；永久ID、归属、状态、当前/已消费数量 |
| `rearInventory/frontInventory` | 按上述归属派生的物理量；隔离物资仍计仓容 |
| `availableFrontInventory` | 可用前线量；与物理存量分开，过期/消费后为0 |
| `shipment` | 本次E8发运/到账、T9可用、路线候选及输入绑定；原材料中的E6/E7历史入库时点不覆盖 |
| `transport` | 真实上限、SP占用、当前预留、已用货运、剩余；`cargo`是固定收费规格，勿与`freight`再加一次 |
| `terminal` | 一次性目标绑定8W凭证，已付/已消费/过期；不能替代整条线路 |
| `receiver` | 本次C10限定仓容和在途空间预留，不是SP仓容量 |
| `recovery/expired/blockers` | 实际恢复回执、到期和当前展示原因；仍须提交时重验Core，视图本身不授权 |

限制：仅单进程、单实例隔离实验，未接HTTP，无跨进程或崩溃持久化；未合并、未部署。35项全局阻塞以及德9／苏14 SP来源缺口保留。本结果只证明本切片链路可执行，不宣称长期收益、完整工业循环或全局平衡。
