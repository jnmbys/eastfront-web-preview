## 三分钟后勤操作

1. 顶部“待办”或军团详情点缺供部队。查看日常供给、携行储备、缺员／缺装备和本步实补；展开“补充通路”查看**具体来源、铁路、枢纽的容量／占用／余量**。同一能力会出现在多条路线，不能相加。
2. 顶部生产入口→补给网络可设置枢纽机动化，定位并显示覆盖。缺库存应调整生产，缺卡车／火车应分配车辆线；不是每种短缺都能靠升铁路解决。
3. 建设队列选择新铁路／枢纽，暂停后点“地图选接入点”“地图选终点”，再预览。虚线只表示拟建路径；确认后进入同一民厂队列。状态变化会使预览失效。新铁路每段8工时（特殊地形、已有桥另计），枢纽24；具体规则见RULES.md。
4. 继续时间后真实施工、配送和部分补充自动发生。工业、民厂和车辆都有限，调拨的机会成本仍然存在。保存后可关闭本轮服务；启动后加载默认暂停。

## 启动与关闭

在本工作目录运行 `node ai/local/build.mjs`，随后 `powershell -NoProfile -ExecutionPolicy Bypass -File experiments/grand-economy-002/start.ps1`。启动器检测4239/4240占用，不覆盖已有服务。

关闭：`powershell -NoProfile -ExecutionPolicy Bypass -File experiments/grand-economy-002/stop.ps1`。只核验并停止本轮脚本的监听进程，同时关闭4239/4240；先在各页面暂停、保存。**不要结束全部Node进程**。磁盘保存位于 `%LOCALAPPDATA%/EastfrontSaves/grand-economy-002/normal.json` 和 `mid.json`，原浏览器验收完整局备份为 `browser-validation.json`。
