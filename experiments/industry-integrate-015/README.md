保留014/009已审计模型的全部网络、来源、铁路/T/W、仓容、守恒与配送上限；新增有限整数付款状态，严格约束`实付=min(应付,期初库存+配送)`。一级目标为各单位`max(参照实付−候选实付,0)`之和，多付不能抵消另一单位少付。二级最小化相对参照新增掉步；三级最小化从E8起点跨D=1或2的人数，同单位跨两档只计一次，另列相对参照新增恶化。

每级均须HiGHS status=0并冻结最优值。随后按普通单位ID升序逐项优先保留实际维护，再最大化储备配送及仓储余额、按ID收束配送、最小化运输工作并逐项收束弧流。没有预设装甲或侦察部队为牺牲对象；**G-REC-02是这套确定性同价规则选出的唯一推荐，不声称其独有战略最优性**。

独立下界来自014新E8约束行：相关必要净配送56q，GH1最多32q，便宜目的地折扣至多24。若总维护减少R q，必要配送最多减少R q，故`GH2工作量 ≥ 5×(56−R−32)−24 = 96−5R`；货运后上限88，整数R至少2。求解器找到且证明2q，并由完整弧流/约束证书验算达到下界。这一数值是本次独立求出的，不沿用旧010。

完整两阶段算式、每单位所有付款状态、全部目标值、弧流、容量、双方单位及库存对照见`RESULT.json.gz`；`RESULT.json`是较小的代价摘要。`SOLVER-SEAM.patch`保存相对014模型的改动，`INPUTS.json`保存输入和派生文件摘要。
