# INDUSTRY-INTEGRATE-018

同一实例从原012真实T5下单起点执行到T9前线恢复：**拨款与订单 → E5/E6生产 → T7后备人员申请 → E7接驳 → T8照管 → E8前送 → T9恢复**。七种操作通过本机HTTP执行，不载入已完成终态来替换当前游戏。

固定012、013、016、017-R1及UI-005输入列在`INPUTS.json`和`LOCAL-SCOPE.json`。仅新增本目录，原Core、候选、授权、旧实验及UI-005不修改。

## 启动、关闭、复跑

需要已有Python 3.12＋NumPy/SciPy、Node 24；浏览器验证另需Playwright与Edge。不安装软件或付费资源。

```powershell
# 仓库根目录。使用原017环境；可传-Python或设置INDUSTRY_PYTHON
& ./experiments/industry-integrate-018/start.ps1
# 打开终端完整 http://127.0.0.1:8818/#session=... 链接
# 关闭：启动终端按Ctrl+C
```

若已有017-R1的准备目录，可以只复制并逐文件核验固定运行依赖，不重建或重跑旧战役：

```powershell
python experiments/industry-integrate-018/prepare.py --runtime-source C:/path/to/industry-integrate-017/.runtime
python experiments/industry-integrate-018/local_server.py --port 8818
```

无缓存时`prepare.py`在用户目录下新建并清理`i18-*`专用短路径，恢复固定017准备器，以避开Windows归档长路径限制；不写旧017目录。启动端口固定监听127.0.0.1，端口占用报告错误，不终止其他进程。刷新仍是同一实例；关闭后进度不保存，不能将旧实例请求重放到新实例。

```powershell
python experiments/industry-integrate-018/verify.py
# 可选命令行真实主线，不开启HTTP
python experiments/industry-integrate-018/probe.py
```

验证使用随机本机端口并在finally关闭监听和事务线程、求解子进程。`PLAYWRIGHT_MODULE`可指定已有模块路径；默认找本机Codex所带Playwright。不要运行旧实验的verify覆盖旧证据。

## 衔接和身份

012和013原命令ID参与Core日志及根摘要，因此继续由服务端使用原规范域命令ID，实际执行并重新生成回执。新HTTP请求使用自己的UUID及永久首次绑定。**没有从TRACE复制回执或预算。** T7实时根必须精确等于`d623bf42b187ca4529ea676fe3963b1016bc82d3c93a28a78a67cabcf8abd5c7`；T8实时根必须精确等于`759ac0d6510d7e0fad38be2c8464623c700d73afc172026faece84c6d6a3e09a`。分别保留22、37份永久回执。

`owner.py`只从012原始constructor新建一次。阶段切换的013/016派生constructor改为接收本次执行所得根并核对原摘要；013新增原定义的空人员分账/注册结构，原activate操作才导入那一次1P及独立2I；016继续当前根。原预算、永久ID、装备数量、人员期限和已有收据不变。

原各阶段事务只作用在私有副本，最终由一个`_head`发布游戏、各账本、原回执、阶段交接和018交易回执；提交前故障丢弃副本。最外层单所有者替代旧阶段各自的独立进程登记，保留串行锁和唯一match。每笔原事务继承同一外层3秒截止，不能靠切阶段重置预算。HTTP会话/首次拒绝登记在外层进程内保存，不被较新的成功状态回滚。

全部派生差异见`SEAMS.patch`：包名/查询路径重定位、继承总截止时间、接收实时根的constructor、统一所有者及到期函数导入。生产、人员收费、配送、Core/SP效果和固定015方案未重写。加载时核验全部runtime文件，原审批仍严格校验；本轮本机接续授权单列，不修改原空批准字段。

主路径无需新增规则权限。**异常根不自动扩大授权**：例如E7拒收留下在途人员，T8根不再符合原016固定切片，交接会拒绝；保留已付接驳、归属与原期限，不借用正常根继续。另有原授权内无照管E8到期、未恢复E9到期的测试分支。未来若要支持其他到达时点、路线或异常根继续前送，需要另行决定，018不代批。
