## 复跑

需要Git对象库含007、规则005及其固定依赖，Node v24.19.0、Python 3.12、numpy 2.3.5、scipy 1.17.0。从此分支仓库根执行（`python`须指向有这些依赖的解释器）：

```text
python experiments/industry-integrate-008/prepare.py
python experiments/industry-integrate-008/verify.py
```

第一次生成证据可给verify加`--write`；正常复跑重算并比对所有证据项，忽略实测用时和trace字节摘要字段的非语义差异，另核验保存trace摘要。`probe.py`仅跑一次真实短路径并输出阻塞，结果写入忽略的`.runtime/test-inputs`。`prepare.py --derive-only`仅用于已恢复依赖后的接缝开发，并先核验固定依赖文件摘要。
