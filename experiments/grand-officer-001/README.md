## 启动、关闭、存档

当前已启动，无需用户手动启动。重开时先在本目录运行 `node ai/local/build.mjs`，再运行 `powershell -NoProfile -ExecutionPolicy Bypass -File experiments/grand-officer-001/start.ps1`。

关闭前先在页面暂停世界并保存，然后运行同目录 `stop.ps1`。它只核对并结束本候选 Node 进程（4229/4230），不批量结束 Node，不操作4228。单纯关闭网页不会停止后台战役。

存档位于 `%LOCALAPPDATA%/EastfrontSaves/grand-officer-001/normal.json` 和 `rotation-demo.json`。自动恢复/读档默认暂停，MP旧连接代次失效。保留独立回执、序号、单位及军团命令代次。

本版存档要求 `tacticalRules=GRAND-OFFICER-001`，保存角色、恢复冷却、撤出路段及阻塞签名。缺少标记的旧模式存档明确拒绝；不自动转换4228旧档。测试存档已另行备份，不是修改用户旧进度。

## 最小规则与边界

- 两阵营共用纯 `planSide(PlayerView, own, groups, memory, tick)`。每5游戏分钟有界重新评估；原400节点路径预算不扩大。仅使用授权敌军位置/公开地形、本方组织、人员、库存与自身历史任务。
- 受托且活着的单位至少4支时，从达标的本军团单位保留1支真实预备队；不借用直属/其他军团单位。合格者不足就不生成预备队。隐藏性格及玩家风险决定撤出与重新投入的门槛，属性不下发。
- 有相邻已识别敌军或正在交战，且组织、人员或库存触发风险时，寻找1格范围内已知己方控制、未满员、公开可通行且无相邻已识别敌军的后方格。未知通路不保证安全。指定撤回目标优先向该目标，其他自主撤出远离目标接触区。
- 非紧急情况最多等待接替2步（10分钟）；紧急情况可留下缺口并报告。接替必须真正行军到位，才能依法参战。相邻且达标者可按已有规则支援，不因支援胜利跟进。
- 撤出现在走真实耗时路段，起点保留到抵达；仍受敌军攻击、到达占位裁决、既有4人追击损失与移动消耗。被包围无路且组织崩溃沿用12人损失。到达组织底限25沿用旧规则。没有改动战斗公式、单位属性、补给或经济参数。
- 撤出途中不获得休整。抵达后至少30分钟冷却，组织达到较高重新投入门槛、库存>=2q、人员>=60%且不在交战才恢复任务。实际人员/装备恢复继续走原库存与支付链。
- 到达被阻后，对同一授权交通/控制/附近占位签名等待，不反复提交失败动作。当前实现没有多格危险撤退搜索，保守的后方判定可能导致停留受损；报告受阻并留给玩家接管。
- 原伤害与反击不变；停止主动攻击不等于敌方停止攻击。新撤出耗时替换仅在本候选类生效，旧模式无钩子时仍走原实现。
- 指定责任地段时，自主交战目标限制在该地段邻域；单点命令只组织目标附近交战。预备与轮换不是完整包抄/战役规划器，仍可能拥堵、接替迟到或留下缺口。
- 铁路、工业预算、全军运输取舍仍由统帅处理；不开发新的后勤策略。双方战略目标继续沿用原实现。

实现：`policy.mjs`（纯决策）、`authority.mjs`（原权威执行接缝与存档）、现有军团面板中的短状态列表。未引入训练模型或新远程服务。
