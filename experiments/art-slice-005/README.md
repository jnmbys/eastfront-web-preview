## Run

Node >=22; locked dependencies supplied by the existing source package:

```sh
npm ci --ignore-scripts --no-audit --no-fund --prefix task-source/ART-PREVIEW-002
node experiments/art-slice-005/build.mjs
node experiments/art-slice-005/validate.mjs
python3 -m http.server 8055 --directory experiments/art-slice-005/dist
```

Open `http://localhost:8055/` (candidate) or `http://localhost:8055/?variant=baseline`.

The build invokes the existing strict frontend TypeScript compilation. It copies only the static module dependency closure from the new entry; no emitted JS is manually patched. Runtime assets are exact tracked WebP files, not regenerated by imagegen during build. `dist/manifest.json` records every runtime file except itself. `_headers` is a platform configuration file, not a served-asset hash target.

Browser reproduction needs Playwright and an installed Chromium. The execution used runtime-provided Playwright and Chromium 133.0.6943.0. Set `CHROMIUM_PATH` to your local compatible browser and run:

```sh
node experiments/art-slice-005/browser-check.cjs
```

The script serves on an ephemeral local port, operates actual DOM and pointer/touch inputs, writes real screenshots and logs. It uses CDP cache clearing for local cold/warm comparisons. It does not visit or deploy a public site. `validate.mjs` writes the per-cell/per-edge audit and eight boundary tests.

## Reuse / isolation

- Reused unchanged: canonical `importLegacyMap`, `geometry/hex`, `deriveBridgeGeometry`, `viewBoxForHexes`, `renderCounter`, counter placement/stack offsets and mapInteraction drag/pinch/zoom functions.
- Baseline is the actual unchanged ART003 `surveyMarkup`, clipped to exactly the same 35 cells; same counters, camera, selection and inspector. It is not the current production renderer and is labelled as the engineering baseline.
- Uses the existing Canvas-under-SVG rendering approach. Only this tiny static terrain is painted once; camera transforms the shared parent. No WebGL replacement, per-tree DOM, per-frame terrain repaint, Core edit or backend connection.
- Exact public map data is imported into canonical coordinates. All 33 touching edge records are retained, including cropped boundary connections; river centers follow shared hex edges, transport follows centers, two bridges come from the existing importer. Rendering is clipped to the 35-cell union. The original map has road/rail co-located on several edges; railway visually dominates those shared corridors and the inspector explicitly identifies both.
- River junction corners are rounded inside a 3-world-unit envelope, bank edges vary slightly inside their corridor. Decorations do not change adjacency, cost or click ownership. The SVG polygons remain canonical hit targets.
- Forest/building sprite footprints are inside their own semantic cell and kept outside transport/river envelopes. Hill/rough stamps are clipped to their own terrain cell. Static terrain is below all units and has no pointer events.
- Four public display fixtures (including a damaged engineer and a two-unit stack) are for selection testing only. No live session, fog, rule action, move/combat simulation or hidden-state query. This task proves an interactive map, not a playable battle.

## Controls

Drag to pan; pinch, wheel or ± to zoom (existing 1–2.5 range); 全览 resets the camera. Click terrain to inspect original terrain/edge flags; click a counter and choose either same-cell unit in the panel. 格线 toggles grid and labels. 切换基线 preserves the exact scene/camera. Measurement tools are inside the scrolling side panel. Buttons are >=44×44 CSS px at the two tested sizes.
