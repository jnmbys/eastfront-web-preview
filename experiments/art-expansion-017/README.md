## 复用能力与固定依赖

| 能力 | 可复用部分 | 扩图限制 |
| --- | --- | --- |
| 城镇组合 | `map015Layout.ts` 的U/L/双院落组合、可用空间打分、有限补位 | 68×68单位净空、标签框、交通宽度均为世界坐标常数；拥挤城市可能无屋顶 |
| 森林疏密 | 邻接林地决定核心偏移、边缘冠幅；共享森林图集 | 每格至多两团冠层；相同轮廓和被裁开的林缘仍可识别 |
| 山脚和体积 | 010山体图集、尺度/长宽变化、地表接触阴影 | 两种山形的轮廓重复明显；不可旋转或镜像烘焙光照来伪装变化 |
| 河岸 | 真正共享边生成连续水线，先岸后水，桥由输入显式给出 | 012局部弯曲限于原8格；通用模式仍能看到六边形折线 |
| 材质与缓存 | 五张图集、既有预处理、一个静态主画布、一个重复使用的小缓冲 | 每次重绘仍会解码/预处理；没有分块驻留或可见范围裁剪 |
| 坐标及尺寸 | hexPolygon/hexToPixel、viewBox、邻接与世界布局接受任意有效坐标 | HEX_SIZE=42；美术、单位、标签、道路尺寸并未统一参数化 |
| 特定地标 | X14及原8格认可构图保留在015默认模式 | `composeSettlement`、局部地面原先无条件寻找X14；无法直接用于独立样片 |
| 入口 | 既有画布、SVG命中区、单位和拖缩代码 | createSlice固定32×20及58个展示单位；X14初始定位不是可扩图入口 |

017仅增加显式的通用实验模式：绕过原8格手工构图及其地面烘焙，调用同一个
015绘制器与布局函数。默认015行为继续保留，原布局与固定源码逐项相等。
这不是新渲染器。合成数据通过独立工厂提供，不写回正式地图。

## 样片说明

60格以12×5轴坐标排列，使用超出正式地图范围的临时坐标；这些数值不是新地图
地址建议。上方安排密林、疏林和山脚，中部安排不同街区与连续河岸，下方保留
铁路、单位和工业候选净空。道路、河流、一个桥点都只是显式合成测试连接。
两枚TEST单位用于选择及堆叠消歧，没有游戏会话、移动或工业功能。

工厂、仓库、铁路站场只显示虚线候选框和“无功能”文字。38×20的框仅用于
检验占位与点击穿透，不是设施最终尺寸；不添加新建筑图集、支线、障碍或规则标志。
工业类型、数量、真实位置和外观体系全部待设计决定。

同视口1363×936，以原015全图适配比例校准世界单位缩放；300%和500%的截图
分别保持相同尺度与选中TEST-1。017小画布栅格密度为2 px/世界单位，不能拿
其清晰度或耗时直接证明扩大后的正式地图表现。

## 扩图前必须确定

1. 地图格数、长宽比、六边形方向、坐标原点和边界；格距对应距离及时间尺度。
   在这些决定前，不按公里或工业产能定义美术大小。
2. 城镇/工业是否共格、单位最大堆叠数、标签与交互热区最小尺寸，设施净空优先级。
   AC10及样片BN36说明：不能要求一格同时容纳完整屋顶群、交通、标签和大单位牌。
3. 河宽、桥头与铁路站场允许的视觉范围及真实连接来源；美术不可推断新增跨越。
4. 与世界坐标解耦的稳定美术种子/地标ID、邻接输入及风格组合上限。
   现有 `q*31+r*17` 经模2/3/4取值，同一邻接平移12列会产生相同相对布局；
   变动坐标原点还会改变外观。先确定身份与种子契约，再扩展组合，不急于增加图片。
5. 最大常用缩放、目标设备、可接受画布/纹理解码/DOM预算及分块边界的邻接余量。
   当前主画布最长边上限4096；地图加大时会降低每格像素，而不是自动提高细节。
   逐格扫描连接/单位以及未虚拟化SVG层也需先评估。此次未实现分块缓存或空间索引。
