## 一致口径

国家库存S不含已经补入部队的装备，但包含仍归国家所有、已指派运输的车辆。部队缺额F只统计当前授权己方存活单位的编制减真实持有量。运输需求T包括当前申请的枢纽机动化及实际网络火车需求，并至少覆盖本周期已经占用的车辆。

总需求G=T+F；净缺额=max(0,G-S)，国家库存仅扣一次。已占用O：卡车为真实枢纽分配，火车为向上取整((日常运输工作量+本小时已承诺补充工作量)/每车能力)。空闲=max(0,S-O)。补装仅用空闲，不能把已用于补充运输的火车再次发给部队。未满足的运输需求仍不是已经占用的车辆；没有新建预留或免费分配规则。

需求判断、连续缺额计数、目标生产排序、调出线排序及UI均使用上述统一数据。保留每6游戏小时检查、连续两次缺额、24小时最多调拨一厂、原有建设搜索预算。原成本、产能、分配顺序、战斗和补给参数未调。队列判断增加本方side限定。
