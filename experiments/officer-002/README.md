# OFFICER-002 · 大战略军官委托

独立分支 `officer-002-grand-integration`。地图、场景及经济基线：`59609befff9900366786ab1d1661330870b5efa9`；选择性复用军官001 `f9089d0919b896c6a7a7bee74ccd17e57b9db7f6` 的公平策略、三名原创军官及界面。未改地图工作分支、Core、规则、RNG、生产价格或运输结算器，未合并、未部署。

## 一个入口

本机地址：http://127.0.0.1:4192/ 。在本候选仓库运行 `powershell -ExecutionPolicy Bypass -File experiments/officer-002/start.ps1`，使用现有 Node 与项目依赖，不自动安装。关闭运行 `powershell -ExecutionPolicy Bypass -File experiments/officer-002/stop.ps1`。也可前台执行 `node ai/local/build.mjs`、`node experiments/grand-campaign-001/server.mjs 4192`，用 Ctrl+C 关闭。只监听127.0.0.1，不是公网部署。

选择默认“大战略实验战役 · 1280格 / 120单位 / T1”，再选德军或苏军。两边各60单位初始均直属。场景仍按原配置从德军T1开始；选苏军不会改回合顺序。沿用大战略的双方轮流人工接管，**未新增自动敌方全军AI**。结束一方阶段后，顶部明确切换授权视角，再确认接管；每个阵营可分别启用军官。

1. 开启“军官委托”，选择军官、己方单位，点击“交给此军官”。同一单位只有一个归属。
2. 进攻/守备使用“在地图选择命令目标”，点地图后明确“确认下令并执行”。COMMAND普通计划不构成授权。整补无需目标。
3. 军官自动连续执行本组可行行动；其他直属单位仍可手动操作。全军结束阶段由玩家决定。无候选、规则拒绝或全局待决时显示原因，不无限重试。一次真实拒绝暂停该军官，其他已授权军官仍可调度。
4. “暂停并人工接管”或“调回直属”撤销新提交权限。正在搜索的未提交决定按授权版本丢弃；已经生效动作不会撤销。跨编组联合攻击请先暂停相关军官，再手动组合。
5. 关闭模式交回人工。命令跨阶段/回合保留；换边隐藏对方编组、记录和目标。刷新后重新进入大战略可重连当前本机内存实例，明确“继续原命令”才恢复调度。退出新局或关闭服务结束实例；无跨进程存档。

## 资源语义与人工事项

RP额度是当前阵营余额上的自动使用上限，**不是新增RP，也不是阻止直属使用资源的托管预留**。额度变更只改授权；实际支付后扣未消费额度、累计已实付数。调度时再以全军当前余额封顶；暂停、重新编组、刷新均不返还已支付资源。

固定大战略基线中RP初始0、恢复RP费用0，恢复实际由原事务消耗同格已可用 **1P＋2E2**，并满足原Core资格及本方每T最多6单位的共用计数。没有为演示非零额度添加RP。军官整补可提交本组材料恢复，实际仓储和恢复次数每次重新读取；两组不能重复支付同一批材料。001中真实1RP恢复及额度守恒证据沿用[owner-check.json](https://github.com/jnmbys/eastfront-web-preview/blob/f9089d0919b896c6a7a7bee74ccd17e57b9db7f6/evidence/officer-001/owner-check.json)。本轮原场景材料恢复已实测。

军官支持本组移动、目标附近攻击、能完整归属同组的损失/撤退/推进选择、恢复和筑垒。铁路、部署/增援、HQ/炮兵及无法归组的反应、混合编组战斗、工业下单、全军共享运输取舍、全军阶段结束仍是统帅待办。后勤报告只依据己方受损和缺供信息；不代付工业预算、不削减其他组维护。本轮沿用大战略既有维护优先和货运规则，没有把004的T5限定事务搬回大战略。

## 实现边界

军官策略只接收当前 FairHost 投影、己方可用材料信息和公开地图/规则；Node Worker不持有权威局面或合法性查询。每次真实行动后重读。名单从当前合法己方单位生成，目标检查当前公开坐标，不依赖德军、T5、某单位或640格地图。场景文件及地理数据保持原样，可单独替换。

三种性格参数未调整，复用001真实同视图行为对照：[policy-check.json](https://github.com/jnmbys/eastfront-web-preview/blob/f9089d0919b896c6a7a7bee74ccd17e57b9db7f6/evidence/officer-001/policy-check.json) 的 `logistics_personality_changes_candidate_same_authorized_view`（缺供下实际MOVE与不移动差异）及明确占优路线同选检查；[史料对应](https://github.com/jnmbys/eastfront-web-preview/blob/f9089d0919b896c6a7a7bee74ccd17e57b9db7f6/experiments/officer-001/HISTORY.md)。不新增史料、头像、性格，不宣称训练模型或战力提升。
