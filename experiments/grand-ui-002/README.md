# GRAND-UI-002 使用说明

入口：http://127.0.0.1:4228/ （仅本机）。进入共同战役；当前独立实例保留密集交战片段，世界暂停。点击继续会推进真实战役。

- 缩小：军团按局部地域成组；切角虚框表示跨格群组，实体矩形/背卡表示单格部队。小圆点及引线指向实际分布，不代表单位搬到标签位置。
- 点击标记展开成员，再点单位选择；这两步不发作战指令。定位另有按钮。缩小后金色选中标识仍跟随该单位所属标记。
- 放大：按同格、同军团显示双条，展开逐队选择。组织、人员及低组织/缺供/缺装沿用原口径。近景不会把同格所有卡片铺开。
- 战斗、城区和原下令方式继续使用。远景淡化非重点箭头，选中部队或战斗会突出有关行动；全箭头开关仍在原工具区。
- 离开前暂停、保存。刷新或读档后请重新选择需要指挥的单位；存档不保存显示聚合。

## 启动、关闭、回退

本次交付时服务保持运行，无需再次启动。关闭前在页面暂停并保存，然后在本目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File experiments/grand-ui-002/stop.ps1
```

该脚本只停止4228且核对本候选进程命令，不结束其他Node。再次启动：

```powershell
node ai/local/build.mjs
powershell -ExecutionPolicy Bypass -File experiments/grand-ui-002/start.ps1
```

独立存档：`%LOCALAPPDATA%/EastfrontSaves/grand-ui-002/campaign.json`；日志同目录。独立启动脚本使用隐藏后台进程，页面关闭不终止服务。
回退直接打开 http://127.0.0.1:4227/ 。该旧服务、存档和内存没有改动；无需切换或覆盖其工作目录。

默认无存档时仍使用原正常战役起点。`prepare-evidence.mjs`仅供复现本次前后截图：明确转换旧密集战斗的领土视野记录，且拒绝覆盖已有本候选存档。不是普通旧存档导入功能。
