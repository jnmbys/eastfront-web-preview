# ART-UI-022 · 本地网页候选

该候选接回015地图材质，保留底部操作台和两枚具象物资图标。不是021生成图的可点击贴图，也不是完整战局界面。最终视觉仍待用户查看。

## 本机运行

沿用已安装、具有 NumPy/SciPy 的 Python 和现有工业018目录，无需重新安装环境。仓库根目录执行：

```powershell
node experiments/art-ui-022/build.mjs
./experiments/art-ui-022/start.ps1 -BackendPath <018目录>/experiments/industry-integrate-018 -Python <既有Python路径>
```

打开终端输出的完整127.0.0.1会话链接。仅绑定本机；链接含本次会话凭证，不放入Git或分享。默认端口8822，可用 `-Port` 指定其他空闲端口。`-Check` 只检查固定后端，不创建事务。没有任何部署步骤。

初始为真实T5下单前。先领取原10I，再下单2 E2；之后按界面的阶段提示推进。T7启用独立人员账户并申请接驳；T8照管前应看到后方1P＋2 E2、装备5I、人员余0I／已支2I，照管1I未支付。所有推进和业务都必须点击，不通过设置回合或改账本跳转。关闭服务后本机进度不保存。

顶部可切换历史模式；“说明／模式”内的原界面链接打开同实例INDUSTRY-UI-006。原页返回候选用浏览器后退或同标签页访问 `/candidate/`。这不会清除原请求锁。地图X14、A10、G-I-01为真实坐标定位；A10在镜头外时明确标注。格位可点选、地图可拖动、滚轮／双指缩放；详细账本按需打开。
