## 启动、使用、关闭

在本分支仓库根目录运行：

```powershell
& ./experiments/industry-integrate-017/start.ps1
```

启动器优先使用`-Python`参数或`INDUSTRY_PYTHON`，否则使用Git主仓库已有`.venv/Scripts/python.exe`，再回退系统Python。需要Python 3.12＋NumPy/SciPy、Node 24、Git；不会自动安装软件。第一次使用会恢复本目录内的私有运行依赖，不重跑旧战役。

终端输出`http://127.0.0.1:8817/#session=...`，打开**该完整链接**。凭证随后从地址栏移除，保存在该标签页会话中。只访问裸地址不能获得操作凭证。默认端口8817，也可`-Port 8818`；地址固定127.0.0.1，不接受对外监听参数。

按页面三步操作：先付照管，再逐次点击“推进下一合法阶段”，到T9德国恢复阶段点击恢复。下一步描述来自后端当前Core。E8运输是原阶段结算的一部分，没有独立运输或扣费按钮。本操作页主动停在T9恢复阶段/恢复后，不提供继续到E9的按钮；016原到期规则不改。若跳过照管，人员仍在E8结束隔离，不能恢复。

**关闭：在启动终端按Ctrl+C。** 等待当前串行事务完成后关闭服务和原求解工作进程。端口占用会明确报错，不终止占用者。页面刷新仍连接同一实例；服务关闭后本次进度不持久保存。重新启动生成新的实例ID和随机凭证，禁止把旧请求自动重放到新实例。

显式运行方式：

```powershell
python experiments/industry-integrate-017/prepare.py
python experiments/industry-integrate-017/server.py --port 8817
```

## 实现边界

`bridge.py`只把三种有限意图转换为服务端生成的016请求。启动创建一个`Transactions`主实例；没有HTTP导入、重置、存档、预算、授权、方案或任意Core命令入口。`LOCAL-SCOPE.json`保存本轮本地HTTP批准，016原授权文件字节不改，未扩大规则权限。

首次合法格式请求按ID登记完整原文；首次内部016绑定只生成一次并冻结。重复内容返回原进度/结果；同ID不同内容409拒绝。旧版本或不可用操作固定记录为拒绝，不在未来重新报价。串行工作队列调用原016`submit`，保留其完整状态哈希、版本、资格和单根提交。相同版本的竞争只有一个成功；失败不产生部分领域状态。

HTTP返回202仅表示登记，不表示扣费成功。页面点击后显示处理中，正式账本只在确认后从`GET /api/state`更新。网络断开/超时显示“结果待确认”，查询同一个请求ID；不会自动用新ID重发。原请求保存在**标签页sessionStorage**，刷新后继续核对，多个标签页互不覆盖。确需重试时按钮发送原封不动的首次内容。服务重启导致实例ID变化时，只允许人工放弃旧请求标记，不自动提交。

每个新实例使用256位随机会话凭证。API需要`X-Local-Session`；写入还要求精确同源`Origin`。`Host`必须是实际127.0.0.1端口，拒绝跨源/`null`来源、跨站Fetch、重复安全头、伪造凭证及多余业务字段；不开放CORS。请求体仅JSON，最大2048字节。静态资源白名单＋CSP，不加载外部资源，不记录凭证或请求正文。

保留原016每笔事务3秒预算；HTTP排队、读取视图、网络等待另计，浏览器等待超时不能解释为事务失败。所有权仅在一个进程；原临时求解工作进程只计算，不拥有或持久化状态。
