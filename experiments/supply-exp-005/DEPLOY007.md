# SUPPLY-UX-007 独立在线候选（未部署）

## 最小拓扑与隔离

复用已有 Render 平台和本仓库代码；另建独立 Docker Web Service `eastfront-supply-ux007`，不连接生产 WSS、不导入生产环境变量、不更改 source-main 服务。HTML、字体、Python 求解器和 Node Core 放在同一服务，同源 HTTPS；不需要 Pages/CORS、数据库、对象存储或 WebSocket。静态站点不能运行 SciPy 求解器，不能以静态模拟替代。

候选入口 `online.py`：浏览器首次 GET /api 创建随机256位会话 cookie（HttpOnly、Secure、SameSite=Strict），4席上限、30分钟闲置过期；每局独立 state/initial/receipt/request journal。单个浏览器是可切双方的个人热座，不是双人房间，也不是双方身份鉴权。不同浏览器无权读取或重置其他会话。服务重启丢失进度；当前不提供恢复登录/跨设备存档。

所有引擎调用由进程内全局锁串行，保留 EXP006 单例求解器/FRAMES 语义；忙时立即503，UI说明未提交，不排无界队列。只允许一个应用实例/进程，禁止以多worker方式启动。Python仍调用真实 Node Core，规则/费用/3秒整次事务冻结。

在线白名单：/、/api、/options、/ux007.js、/fonts/*、/healthz；/replay、源文件和测试夹具不可获取。仅允许同源 JSON POST。总最多8个HTTP处理线程、20KB请求体、5秒读超时、150次新操作或6MiB序列化状态阈值后要求导出重置；最多8次新建会话/分钟。请求ID/版本/原子提交继续来自EXP006。容量限制保护资源，不是防恶意占座的完整系统；链接仅用于有限试玩，不能称公开生产服务。

## 准备好的启动路径

在批准部署后：从本交付SHA取 `experiments/supply-exp-005/` 作 Docker build context；使用这里的 Dockerfile（Python3.12、Node22、TS5.7.3、固定NumPy/SciPy）。构建先恢复分片夹具并核对哈希，再编译Core。以非root用户运行 online.py。

单实例；端口环境 PORT=10000，BIND_HOST=0.0.0.0，COOKIE_SECURE=1，PUBLIC_ORIGIN=https://实际独立服务域名（必填，不能是生产域名）。健康检查 /healthz。关闭自动部署、PR预览、自动扩容；只手动发布批准SHA，不建Hook。部署后独立测试HTTPS cookie、Origin、2浏览器隔离、3片段真实结算、预算与内存，再让用户使用链接。回滚只切此独立服务的前一镜像；关闭也只关闭此服务。

本轮没有 Docker daemon，Dockerfile未实际build；已验证干净实验子树恢复与本地编译/启动，不能替代镜像或Render验收。当前没有可供平板打开的线上链接。
