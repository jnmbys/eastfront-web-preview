# SUPPLY-EXP-005 · 可撤销实验合同 v1

固定 A、完整回合末双方统一结算、T 开、末端范围8。Q=4；需求 B、储备上限、逐级公平、来源/共享铁路/桥/W/T 约束、债务与恢复沿用 EXP004。时钟及数值不定为生产规则。

## 顺序与原子边界

校验请求 ID/版本/当前控制器 → 将库存/债务投影到隔离 Core 的行动参数 → 候选副本中接受真实 Action，战斗后续完成 → 一次扣行动消费并按稳定 ID 迁移 → 仅当苏军筑垒结束使 Core turn 增加，双方按同一拓扑配送/维护/债务结算 → 将本次后勤损耗转换为真实 Core 步损/消灭 → 再迁移注销库存 → 总账校验 → Core、后勤、epoch、请求 ID 和回放一起提交。

3秒为整个事务的总预算，包含 Node、Python求解、IPC和复核。任何失败/超时均返回原对象，不提交部分状态；旧 revision 拒绝；相同请求 ID/内容幂等，不同内容拒绝。维护不由独立按钮触发，重复 END 请求不能增加物资。服务仅监听 loopback；不接生产存档、房间或部署服务。

## 行动与短缺

- 直接攻击的每个单位支付最多 1 SP。未足额仍可攻击，系数为 min(0.5+0.5×实付/1SP, 债务系数)。D<1:1；1≤D<2:0.75；D≥2:0.5。逐单位攻击值向上取整，然后执行原地形、CRT、修正和骰子流程。
- PANZER/TANK/HEAVY_TANK/MOTORIZED 每次普通 MOVE 消费最多1 SP，沿用既有装甲机动包。步兵不加机动费，防御及被迫撤退不另收费。未足额机动不再增加一重支付惩罚；维护债务仍积累。不借贷、不负库存。
- D≥2 普通 MOVE 的总 MP（包括公路加成）封顶1；无额外穿林、涉河、堆叠、占军或ZOC特权。D<2原移动值。
- D≥2 使用兼容状态标签关闭 Core 原有的补给资格门槛：突破/重点、炮兵/HQ、联合兵种、修复/工兵修路等。门槛现在只来自债务。旧半径快照不再生效，旧移动扣值/攻击乘数/OOS包围防御折半关闭。没有新增防御倍数。
- 足额维护使 D 每完整回合减1；不足按原比例增加，封顶3。D=3且不足的原损耗累积满1，实际扣 Core 一阶；到模板阈值则消灭。只扣一次，单位剩余库存进入注销 sink。
- 修路只改变通路，不立即配送、补仓、清债或退款。Core 战损不额外降低需求或库存上限，避免临时引入另一套机制。

## 本轮必须补足的显式默认值

1. 原沙盘机动包没有 Core 接口：本轮只映射上述装甲/摩托普通 MOVE；不扩展燃料、运输装备或逐车操作。
2. 原影子 strength 与 Core step 分离：本轮每次后勤损耗只转换一次为实际 step/alive，随后以 Core 剩余阶数同步，不复活、不双扣。
3. 增援携行0，不凭空增加物资；必须部署时，阶段结束助手用排序后的第一个合法入口执行真实 DEPLOY_REINFORCEMENT。该默认不代表正式增援规则。
4. 实验枢纽敌占仅冻结通行，库存保留；不推断缴获或毁仓。Core control:null 原样保留。
5. 兼容资格门槛采用 D≥2；这是接缝默认，不声称已平衡。UI当前不提供HQ/炮兵/修复单位等完整选项。
6. 战斗防御反应、损失分配及撤退由固定合法策略完成；放弃可选战后推进/突破/重点。玩家自主普通移动、多单位攻击、修路及结束阶段；不是固定 Action 播放器。可选战后决策交互仍未接入。
7. 新模式不执行旧正式胜利谓词；短实验到 T15 后拒绝继续行动。没有选定新胜负规则。

## 三个初始配置

- prepare：EXP004 T4 德军移动前，4B（初始实际3B），其余枢纽/容量沿用。用于比较保存、机动消费与攻击。
- isolation：EXP004 T8 德军移动前，2B（初始B），真实结束六个玩家回合后到T11，再合法进入移动阶段。自然形成债务；无手改库存/伤亡。
- restore：相同T8物理起点，但实验 GH2 固定设在D10，W=512整数工作量、G-A10产能=128整数单位、实验铁路容量=128；其余不变。自然等待三完整回合，停在T11修路阶段。C10–D10未修，仓库失联；玩家可用真实 RAIL_REPAIR接通。

restore 是明确的容量充足对照，不是默认产能推荐。原32产能/96工作量下接通仍不足的结果保存在 evidence/repair-only-still-insufficient.json；没有通过免费增加库存制造恢复。更早“撤离A5但配送走廊未清空”的失败也保留。这里验证的是未修线路接通，不冒充合法破桥/炸铁路复现。

## 账本、旧模式和权限

初始物资 + 实际来源注入 = 单位/仓库现存 + 维护 + 实际行动消费 + 消灭库存损失。节点/单位稳定身份迁移沿用 EXP004；实验容量不随快照重置。

旧模式运行原 Core 补给和hooks，不消费新资源、不结算新债务、不写入 expSupply；模式只能重置时选择。旧模式中的实验库存不是该模式行动资源。

玩家 DTO 复用 EXP004 白名单，追加本方 Core flags 和本方效果。路径候选只用授权敌军的副本，未知区域标条件，不读取隐藏阻挡作预测；只列1–2步，不声称完整可达域。实际非法/超时提示泛化。全知回放只能显式选择研究导出；本地热座可主动切换双方，不宣称联机鉴权。

完整回放是 initial + adapter journal：包括真实 Core Actions、后勤结算与实际补给步损、消费及提交哈希。不能仅用 Core Action 数组重放而漏掉后勤伤亡。供应/RNG算法未修改；失败与重试不推进骰子。
