# GRAND-OFFICER-003

基线：线上 c1c5e080adf1f542ed706c48aea61f99973399f6（Live，1核/2GB），开发从其证据子提交 d836a72 开始。未取得可识别且安全隔离的用户交战存档；本轮使用明确标注的正常新局与定向接替场景，未推进用户原局。

## 操作与边界

选军官 → 绘制战线 → 确认战线并布防。无需进攻目标。设置进攻方向后，另点“开始进攻”。“停止进攻”回到布防；“暂停军官”停止调度，不停止敌人攻击或世界时间。

仅将责任地段内、当前授权视图明确为本方控制且无已识别敌军的格设为可部署岗位。敌占/未知格显示受阻。原责任地段被合法夺回后可重新部署；不向范围外自动扩张战线。到位要求实际处于该格且未在撤出/离岗行军；相邻不算到位。在途接替不算覆盖。

岗位持久化，改线/归属/资格变化时释放。先保留已站岗者和有效岗位，再分配空缺。城市、道路/铁路节点、已识别邻敌及控制交界增加岗位优先级。没有空闲部队时，只有重要性至少高20且原岗未交战、未行军、已分配至少6步，才允许从较低风险岗调人；原岗仍显示空缺，不制造满线。

部署资格：原有组织/供给/人员约束，组织至少35、人员至少60%、携行库存至少1且日常供给有效度非零；既有撤出、整补、等待和受阻战术任务优先。预备队可明确释放去补岗；已执行支援不被悄悄改为跟进。进攻只释放必要岗位实际到位后的剩余部队，每步最多新增释放一队（组织55、库存2）；必要守军保留。兵力全用于守线时，开始进攻不保证有人可投入。

双方共用纯授权输入函数；不调用Core合法性探针。防守路径限当前已知己方地块，复用原地形/过河/占位及耗时裁决。每步双方共用480展开节点，单次80；军团确定性轮转。路径缓存按授权地图、交通、可见占位、起终点与机动能力失效，最多每侧96条。预算耗尽保留岗位；不跳结算。

添加 `clock.frontDefense.version=PERSISTENT-FRONT-1`：岗位、接替对象、轮转游标、有限路径缓存与任务均保存。旧存档缺字段时增加空容器，不改变单位、资源、领土或主动暂停状态；未知扩展版本拒绝。外层规则/存档格式未变。

发布前每个现有访客当前文件原子复制到 `.before-officer003`，原身份文件及最新存档不替换。已验证 c1c5 读取扩展存档、保留状态和不识别字段；如需回退部署该版本并保留最新文件，不能用旧检查点覆盖新进度。旧版不会执行新增岗位调度。
